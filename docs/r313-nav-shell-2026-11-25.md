## 一、工作流收成管理员 Beta（第 1 件）

- 服务端真源 `server/workflow-beta.mjs`：`workflowBetaAllowed(user)` 默认只认管理员（`isAdmin`，含 `VQ_ADMIN_EMAILS`），
  `VQ_WORKFLOW_BETA=all|1` 只给内部实例排障用。`/api/flows`、`/api/runs` 在 `handle` 第一行判权，**早于扣费与读盘**，
  非管理员得到固定 403：`{ok:false, error:'工作流还是 beta，现在只对管理员开放', code:'WORKFLOW_BETA'}`。
- `/api/auth/me` 在响应根上给 `features:{workflow}`，前端只认这一处，不再各页各判 `kind==='admin'`。
- **无限画布不算工作流**：`/api/canvas`（#/board 的票据与排队位）不加闸门，普通账号照旧 200——开发中曾误判过一次，已撤回并写进测试。
- 作品侧：`POST /api/projects`（带 flowId）、`/projects/:id/canvas`、`PATCH flowId`、开新版复制工作流，非管理员一律 403；
  读侧把 `flowBrief`、`project.flowId`、`versions[].flowId`、`?snapshots` 的 nodeList、运行行里的 flowId/flowName/节点输出全抹掉，
  但脚本、分镜、评审、交付、花费、版本历史一个字段不少。
- **开新版不整条拒**：普通账号照常开新版（脚本与分镜跟着走），只是不复制工作流——版本迭代是核心动作，不能因为藏工作流被废掉。
- 前端：`src/domain/features.ts` 是全站唯一开关（`useWorkflowEnabled()`）；侧栏不渲染工作流、命令面板不列、`#/canvas` 直连落在
  Beta 说明页；作品页 / 模板库 / 评审页 / 快捷创作 / 使用引导里所有工作流按钮、徽标、文案按开关收掉；
  作品状态胶囊在普通账号下把「待开工作流」落回「在做」。

## 二、导航与账户区（第 2、6、8、9 件）

- 导航（`src/nav.ts`）：一级四个去处 = 工作台 / **我的作品** / 爆款雷达 / 模板库；**我的资产**提到工作台之下（缩一级、紧跟工作台）；
  工具区 = 快捷创作 / 无限画布 / 视觉评审 / **积分记录**；工作流单独一项、带 Beta 标、只对管理员渲染。
- 右上角账户区（新 `components/AccountMenu.tsx`）：头像 + 名字 + **剩余积分**胶囊，点开是 Codex 式菜单——头像与账号类型、
  剩余积分与「去充值」、使用引导、账号设置、帮助与协议、切换账号、退出登录；左下角账号菜单里同样有余额与充值入口（两处读同一份余额）。
  余额由外壳读 `/api/credits?limit=1`，换页与生成完成（`vq:credits` 事件）时重读，读不到显示「—」而不是 0。
- 头像：服务端 `server/avatar.mjs` + `/api/account/avatar`（GET/POST/DELETE），只认 PNG/JPEG/WebP 文件头、≤2 MB、
  落 `DATA_DIR/avatars/<userId>.<ext>`（0600），版本号存 `users.avatar_version`，URL 带 `?v=` 防缓存；本人或管理员可读，别人 404。
  设置页上传前在浏览器里裁成 256 方图再压成 JPEG；`components/UserAvatar.tsx` 是全站唯一渲染点（圆图 / 首字母 / 加载失败回落）。
- 充值页从右上角菜单与左下角菜单都能进；设置页的积分卡仍在。

## 三、积分记录（第 3 件）

- 账本行（`server/credits.mjs`）从 `run:<runId>:<nodeId>` 解析出运行与节点，补出 `runId / nodeId / nodeLabel / flowId / flowName / kindLabel`，
  并原样带上 `meta`；节点名与流程名从 `DATA_DIR/runs.json` 读（按 mtime+size 缓存，坏文件不挡页面）。
- 页面（`RunsPage`）：余额、本月消耗、去充值；筛选 全部/消耗/充值/退款；每行 时间、动作、说明、增减、结余；
  管理员多一行「节点 · X / 流程 · Y / 查看这次运行」，普通账号看不到工作流痕迹；分页「加载更多」按 offset 追加、按 id 去重。
  管理员另有「工作流运行」页签，普通账号不出现。
- 充值 / 赠送 / 管理员发放 / 管理员扣减都有中文标签，同一份 `SPEND_KIND_LABEL` 给页面与「本月消耗」共用。
