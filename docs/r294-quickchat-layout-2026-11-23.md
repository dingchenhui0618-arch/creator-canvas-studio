# r294：快捷创作的对话框收身（v0.9.276）

用户原话：「对话框窗口太拥挤了 四周留白过多 左侧对话框切换栏过大，收紧一些」。

## 量出来的问题（1440×900，改前）

| 位置 | 改前 | 问题 |
| --- | --- | --- |
| 页面内边距 | 32 / 32 / 64 | 底部 64px 让一屏布局白丢一截高度 |
| 对话区块宽 | 900（上限） | 舞台 1136 宽，左右各空 118px |
| 左栏会话列表 | 240 宽，缝 16 | 吃掉对话区的三成；清单只露 5 条 |
| 会话行 | 60 高 | 21 条会话要翻四屏 |
| 左栏底注 | 107 高（3–4 行常驻） | 挤掉清单高度 |
| 右栏对话线程 | 644 × 302 | 一进来就是「挤」 |
| 1024×768 线程 | 468 × 107 | 空状态卡比窗口还高，被切成上不见标题、下不见尾 |

## 改了什么

只动布局与两处文案，不动结构：**页签两行、输入卡密度、圆角、配色全部保持原样**。

1. `.agx-page` 内边距 32/32/64 → **24**；`.agx-stage` 上留白 24 → 16、底 8 → 0。
2. 平台对话 / 图片 / 视频的 `.agx-composer-wrap` 取消 900 上限，**铺满舞台**（左右那 118px 空白没了）。
3. `.qc-root` 240 + 16 → **208 + 12**；`.agx-media-shell` 跟着改同一个数，切页签时左边界不跳。
4. 会话行 60 → **51**（`.qc-conv-main` 内边距 8 → 4px 8px，标题与元信息 line-height 1.4），一屏多露两条。
5. 左栏底注从三四行常驻收成**一行**（「服务端保存 · 最多 30 个」，全文进 `title`）：107 → 31px。
6. 矮屏（`min-width: 901px` 且 `max-height: 820px`）**空状态那三条说明让位**，只留标题 + 一句话——
   1024×768 上原来整张卡被切成两半，现在 171px 的线程里正好放得下。
7. 会话行的按钮补 `title`（208 宽下标题更早被省略号截，悬停能看到全文）。
8. 图片 / 视频的说明段落到 72ch 断行（这一列铺满后原本一行 140 多字）。

## 边界

- 只量 1440 / 1024 / 390 三个宽度，768 平板没有逐屏再扫一遍。
- 左栏清单最后一行在滚动边界会被切一半（滚动列表的固有行为，改前也这样），没加渐隐遮罩。
- 两行页签（对话/图片/视频 + 平台对话/对话预设）没有合并：那属于信息结构，不在「收紧」范围内。
