# 快捷创作：四个页签长成同一个东西 + 工作流搬进来（r256 / v0.9.239）

日期：2026-11-19。用户原话两句：

> 我是觉得整个工作流页面还是太鸡肋了，跟快捷创作联动起来才有意义，别让它变成孤零零一个独立页。
> 其次快捷创作那边现在的样式就很不统一，对话一个窗口，和图片视频的窗口一点都不靠近。

## 一、工作流从「侧栏里一个孤零零的页」变成创作入口的一种

以前工作流只有侧栏那一个入口：点进去是一张画布，和「这次创作」看不出关系。
现在快捷创作的页签是 **对话 / 图片 / 视频 / 工作流**，工作流这一页签直接摊开手上的流程：

- 每行写明：名字、几步几条连线、在帮哪条作品的第几版、跑过几次 / 最近一次是什么时候；
- 点一行就进那张画布（实测：`#/agents` → `#/canvas/flow_xxx`，画布标题是那条流程的名字）；
- 一条都没有时给两个出口：「去工作流页起手」（从作品 / 模板起手）与右上角「新建」；
- 页面只读元数据，打开不扣积分，跑一次才按次计费——这句写在卡底。

数据来自 `GET /api/flows`（`listFlows()`），「新建」走 `POST /api/flows` 建一张空流程再跳过去。
新组件 `src/components/FlowPanel.tsx`。

## 二、图片 / 视频与对话是同一个骨架

对照「平台对话」那一屏：左边一条列表卡（会话）、右边一块工作面（对话内容）、输入框贴在工作面底部。
图片 / 视频原来是另一套东西——一张 900px 宽、24px 圆角、16px 内边距的独立面板，自己还有标题头
（40px 图标 + 大标题 + 价格）、字段各自带框、底部一颗大主按钮。切过来确实像换了个产品。

改成同一副骨架：

| 位置 | 对话（平台对话） | 图片 / 视频（改后） |
| --- | --- | --- |
| 左栏 | `.qc-side` 会话列表 240px | `.agx-media-side` 最近生成 240px |
| 右栏上 | `.qc-thread` 对话内容卡 | `.agx-media-out` 结果卡 / 空状态说明卡 |
| 右栏下 | `.qc-composer` 输入卡（8px / 14px 圆角） | `.agx-composer--media`（同样的 8px / 14px 圆角） |
| 发送 | 圆形 40px，右下 | 同一个 `.agx-send`（38px，右下） |

顺带去掉的东西：面板自己的标题头（`.agx-media-head` / `.agx-media-icon` / `.agx-media-heading`）、
自带边框的提示词输入框（`.agx-media-field textarea`）、底部那颗大主按钮（`.agx-media-foot`）、
再包一层的参考素材框（`.agx-qc-refs` 在这张卡里变成一行说明 + 两个按钮）。
模型 / 方式 / 比例 / 时长 / 清晰度五颗胶囊移进底部那条 bar，和对话的「对话预设 / 输出 / 模型」同一行。

结果不再挤在表单里：生成中、进度、成功、失败都排在输入卡**上面**，像对话里的消息那样一条条往下走；
「最近生成」搬到左栏，和会话列表同一个位置。

## 四、边界

- 图片 / 视频页签只验了「空状态 + 参数 + 发送键可用」，**没有真跑一次出图 / 出视频**（本轮 0 次真实上游调用）：
  生成中、进度条、结果卡、左栏最近生成这几块用的是同一套已有组件，位置换了、逻辑没改。
- 「新建」按钮只验到接口与跳转路径存在，没在探针里真点（会多建一张空流程留在临时库里）。
- 对话预设那条输入卡（`.agx-composer`，24px 圆角 / 16px 内边距）仍是另一套：它是「高级模式」，
  这一轮没有跟平台对话统一。真要统一，是下一轮的事，会动到预设对话那整块。
- 工作流页签只列你自己看得见的工作流，没有搜索、没有按作品分组、没有「最近运行结果」预览。
