# 停掉的分享链接，打开记录还在（v0.9.11）

上线：2026-11-12，生产 visionqa.wavisionai.cn，版本 0.9.11。

## 为什么做这个

v0.9.10 记下了「链接被打开过几次」，但停掉分享的那一刻，面板跟着分享状态一起消失——
记录还在数据文件里，界面上却找不到。想回看「上周给甲方那一版到底看没看」，只能看正在分享的那条，
或者去翻数据文件。

这一轮把停掉的链接放回作品页：分享面板底部新增「以前的链接」，每一轮一行停用时间，
和那一轮被打开过几次、最近一次与客户端类别。停分享不再等于把这轮记录从眼前拿走。

## 长什么样

作品页 → 分享，不管当前有没有在分享，面板底部都有「以前的链接」：

- 有记录：`11-13 00:00 停用` + `2 次打开 · 最近 刚刚（手机或平板）`；
- 那一轮没人打开过：写 `没人打开过`，不写「0 次打开」；
- 当前分享中：上面照旧是现在这条链接的打开情况，下面是以前各轮；
- 没有任何历史：这一块不出现，面板和 v0.9.10 一样。

停掉分享后不关面板：停用的那一轮立刻出现在下面，不用刷新页面。

## 三个实现决定

1. **历史只存 token 的哈希前缀，token 本身清掉。** 旧地址照旧 404，谁也打不开；
   但哈希键和 `share-visits.json` 里的打开记录对得上，界面上还能显示那一轮被打开过几次。
   这和不存 token 的初衷一致：记录文件被看到，也拿不到能打开作品的链接。
2. **最多 8 轮，按停用时间倒序。** 更早的链接没人会回去看；换新链接时上一轮自动归档，
   不要求先手动停一次（接口被直接调用时也不会丢记录）。
3. **详情接口只给统计，不给记录键。** `shareHistory` 每条只有 `createdAt`、`closedAt`、`visits`；
   列表接口连历史一起剥掉，和 token 一样只在作品页自己出现。

## 量到的

生产真实作品（「毛衣折叠收纳法」，8 镜 8 帧）跑了完整两轮：

| 动作 | 读数 |
| --- | --- |
| 第一轮：开分享 → 电脑打开一次 → 停掉 | 历史 1 条，`1 次打开 · 最近 …（电脑浏览器）` |
| 第二轮：开分享 → 手机打开 → 过 63 秒再打开 → 停掉 | 历史 2 条，最前一条 `2 次打开 · 最近 刚刚（手机或平板）` |
| 停用后访问两条旧地址 | 都是 404，历史里的次数不变 |
| 作品详情 | `share: null`，`shareHistory` 2 条；响应里没有旧 token，也没有 `key` 字段 |
| 分享面板 | 1440 宽 520×384px，390 宽 342×422px，两种宽度 `scrollWidth == clientWidth` |

生产数据目录里：`projects.json` 该作品多了一个 `shareHistory`（2 条，无 token），
`share-visits.json` 里对应 2 个哈希键。作品、画布、评审的数量没变。

## 边界

- **历史是打开次数的历史，不是访问日志**：没有账号、没有 IP、没有原始 UA，也没法回答「是谁」。
- **打开记录文件上限 200 条链接**（按最近一次打开保留）：被挤掉的旧链接，历史里会显示
  「没人打开过」，而不是一个永远不更新的旧数字。
- **删除作品时历史跟着作品消失**；打开记录本身留在数据文件里，直到被上限挤掉。
- **只在作品详情里出现**：分享者（或管理员）看得到；甲方、分享页、分享纸都看不到。
- **老作品不用迁移**：没有 `shareHistory` 字段就读成空数组，面板不显示这一块。
- **停用时间不是「最后一次打开」**：后者在每一行里单独写出来。

## 复验命令

```powershell
# 本地：fixture + 演示模式
$env:DATA_DIR='.tmp-qa/r82-data'; $env:API_PORT='8790'; node server/index.mjs
# 开分享 → 打开 → 停用 → 看详情里的 shareHistory
curl.exe -s -X POST http://127.0.0.1:8790/api/projects/prj_h/share
curl.exe -s http://127.0.0.1:8790/api/share/project/<token>
curl.exe -s -X DELETE http://127.0.0.1:8790/api/projects/prj_h/share
curl.exe -s http://127.0.0.1:8790/api/projects/prj_h
```
