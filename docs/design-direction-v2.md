# VisionQA Workbench · 设计方向 v2

> 结论先行：把「AI 味的通用 SaaS」换成 **VisionQA 产品本来的检视语言**——近黑白、发丝线、取景框、等宽元数据，颜色只用来表达评审结论。

## Design read

Reading this as: **B2B 创作与评审工作台（product UI，不是官网落地页）**，使用者是内容运营、创意和视觉评审人；语言是 **monochrome inspection（近黑白检视）**，对齐 VisionQA 既有品牌资产（Geist + 发丝线 + 语义色）。

| 旋钮 | 值 | 理由 |
| --- | --- | --- |
| DESIGN_VARIANCE | 4 | 工具软件，靠版式和层次取胜，不靠夸张构图 |
| MOTION_INTENSITY | 2 | 只有 120–180ms 的状态反馈，不做无限循环动效 |
| VISUAL_DENSITY | 6 | 工作台，信息密度要高，但不是仪表盘堆图表 |

| 变量 | 值 | 用途 |
| --- | --- | --- |
| `--canvas` | `#f4f4f4` | 页面底色 |
| `--surface` / `--surface-raised` | `#fbfbfb` / `#ffffff` | 面板 / 悬浮层 |
| `--ink` | `#111111` | 主文字、图标、强调 |
| `--muted` / `--faint` | `#5d5d5d` / `#6f6f6f` | 次级文字 / 元数据 |

## 必须去掉的「AI 味」（逐条对照删）

1. 紫/蓝渐变、彩色光晕、大面积玻璃拟态 —— 全删，色块最多两色：纸 + 墨。
2. 所有卡片统一大圆角 + 大阴影 —— 改为 8/10px 圆角 + 发丝线，悬浮层次靠 `--shadow-raise` 微量。
3. 每个标题前的彩色圆点、装饰性渐变下划线、emoji 图标 —— 删；需要标记用 10px 等宽大写标签。
4. 居中「营销式 Hero」出现在工具页 —— 工具页标题左对齐，右侧放操作，不居中抒情。
5. 无限循环的 shimmer/呼吸动画 —— 骨架屏用静态发丝块 + 最多 1.2s 的透明度脉冲。
6. 「AI」「智能」滥用在按钮和标签上 —— 只在真正调用模型的地方出现，且写成动作（`运行` `评审` `拆帧`）。
7. emoji 做图标 —— 统一 lucide 线性图标，尺寸 14–16，`stroke-width: 1.5`。

## 结构规则

- **取景框母题**：只用在「被检视的对象」上（视频封面、帧图、画布产物），用 `.vq-frame` 的四角线，不要给每个卡片都套。
- **等宽元数据**：ID、时长、条数、时间、参数一律 `--font-mono` + 10–11px + `letter-spacing:.04em`。
- **标题层级**：页面标题 26–30px / 600；区块标题 13px / 600 + 10px 大写标签；正文 12.5–13px / 1.65 行高。
- **留白**：面板内边距 16–20px，区块间距 28–32px；不要用 8px 这种「挤」的间距做区块分隔。
- **状态**：任何异步区域必须有 空 / 载入 / 失败 / 成功 四态，失败要写清「哪一步、为什么、下一步怎么办」。

## 各页要点

| 页面 | 要点 |
| --- | --- |
| 工作台 | 左侧品牌 VisionQA；右侧是「今天要做什么」的任务入口，不是 KPI 仪表盘 |
| 爆款雷达 | 检索条贴着内容区顶边；示例数据必须显式标注；卡片用检视框包住封面 |
| 一键复刻 | 弹窗按「来源 → 参数 → 运行时 → 产物」四段推进，运行日志等宽字体 |
| 模板库 | 列表密度优先；详情抽屉里脚本/分镜用表格，不用卡片堆 |
| 智能体 | 对话框式入口（参照晨羽智云快捷创作），底部是「已自建智能体」分类，不是精选作品 |
| 画布 | 节点用发丝框 + 等宽类型标签；连线 1px；选中态用 `--ink` 描边，不用彩色光晕 |
| 视觉评审 | 结论色只有 pass/warn/fail 三种；证据锚点用十字准星标记，指向被检视区域 |

## 反例（看到就改）

- `background: linear-gradient(...)` 出现在面板上。
- `box-shadow: 0 20px 60px rgba(107,98,217,.35)` 这类彩色光晕。
- 按钮里出现 ✨ / 🚀 / 🔥。
- 段落文字用 `#7c7c9a` 这类偏紫灰。
- 同一屏出现 4 种以上圆角值。

## 字体与图标

- Geist（Google Fonts）+ Noto Sans SC 兜底中文；Geist Mono 承担所有数字与标签。
- lucide-react，`stroke-width: 1.5`，默认 16px；不要混用 emoji 或自绘彩色图标。
