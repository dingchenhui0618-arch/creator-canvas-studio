## 一、这一轮补的是哪块空

v0.9.20 给了「已看过」这个出口，v0.9.21 又给了「拍板」。两条都在工作台上留了一行字：

> 已看过 6 条，这一版先没改 · 最近：毛衣折叠收纳法（第 2 版 · 11/13 04:28 看过） **[撤销]**
> 你拍板过 3 条 · 最近：冬季围巾三种系法（第 2 版 · 通过 · 11/13 09:20）· 记录与撤销在作品页 **[打开]**

问题是这行只写得出**最近一条**：6 条里另外 5 条既看不见，也撤不掉——要知道是哪条作品，得自己记住标题、
去作品列表里一条条翻；「拍板过 3 条」同理，只给最近一条的入口。

这一轮把这两行变成**点得开的清单**：点「看这 6 条」就是 6 行，一行一条（状态胶囊 + 作品名 + 第几版 /
评过几次 / 什么时候看过），行尾逐条「撤销」；拍过板的那份每行写人的结论（人工通过 / 人工不通过），
点一行进作品看那一次拍板。默认收着——它已经不是待办，不该占掉首屏高度。

顺手修掉一处真 bug（见第三节）：撤销「已看过」以前按 `ownerId` 硬比，**看得见却撤不掉**的条目点下去
接口返回 200、`removed` 是 0，那一行原地不动，像是按钮坏了。

## 二、三个决定

1. **清单整份给，不砍到 10 条**
   原来服务端 `seen` / `decided` 各 `slice(0, 10)`，只够写一行字。既然界面上写的是「已看过 6 条」，
   点开就得有 6 行——少一条就是假话。现在整份给第一页（`offset=0`），条数天然被「账号里还等在队列里的
   作品数」限住，不另设上限；翻页时不重发（翻页是为了待办，不必每页重复一份看过的）。

2. **拍板那行的胶囊写人的结论**
   `decided` 每行的 `status` 改成 `projectStatus(project, reviews, decision)`——与作品卡片、作品页、
   交付稿同一口径。以前队列只算模型结论，清单里会出现「模型说不通过、人拍板通过」的那一条却挂着
   「评审 · 不通过」，读的人会以为拍板没生效。

3. **撤销改成「看得见就撤得掉」，撤不掉就直说**
   与 v0.9.26 拍板记录定下的规矩一致（`canAccess`）：自己账号的、没有归属的公共记录、管理员看得见的，
   都撤得掉；看不见的照旧撤不动。客户端在 `removed === 0` 时写一句「撤销没撤掉：这条「已看过」已经不在了，
   可能刚在作品页撤过」，不再假装撤成功。

## 六、验收清单

- [x] 点「看这 N 条」排出来的行数与 N 一致（不是最近 10 条，也不是最近 1 条）
- [x] 拍过板的行写人的结论，模型的原结论仍留在评审记录里（行上写「模型「…」」）
- [x] 展开状态下撤销，行与数字当场更新，那一条回到上面的待办
- [x] 看得见就撤得掉（公共记录、管理员）；看不见的照旧撤不动
- [x] 清单只在第一页带，翻页不重发（`offset>0` 时两份数组为空、总数照旧）
- [x] 收着的时候不渲染清单（首屏高度不变），点开才排
- [x] 1440 / 390 均无横向滚动；清单块与待办行同一个形状、同一套胶囊
- [x] 不调模型、不扣积分；生产那次写入当场撤销并核对归零

## 七、边界

- 清单只覆盖「还在队列里的」那部分：作品一旦交付、或后来评成通过，它就不在这两份清单里（拍板的历史在作品页「拍板记录」）。
- 「已看过」仍是便利贴语义：同一版又评出新结论、或开了新版，它回到待办——清单里自然也就没有了。
- 不新增页面、不新增路由：两行小结原地变成可点开的清单。
- 拍板那一份不做行内撤销：撤销与改判要经过作品页的「拍板记录」（那里写清了管哪一版、还算不算数）。

## 九、改动文件

- `server/review-queue.mjs`：`decided` 行的胶囊按人的拍板算；`seen` / `decided` 整份给第一页（`offset=0`），翻页不重发。
- `server/review-acks.mjs`：撤销按 `canAccess`「看得见就撤得掉」，返回真实 `removed`。
- `src/pages/OverviewPage.tsx`：两行小结加上「看这 N 条 / 收起」与逐条撤销；拍板行点进作品。
- `src/styles/overview.css`：清单块、右侧动作、脚注；窄屏动作换行、脚注跟着收 12px。
- `src/api/review.ts`：`seen` / `decided` 的注释改成「整份清单、只在第一页」。
- `test/review-queue-handled.test.mjs`（新，5 条）：整份给、倒序、人拍板的胶囊、只在第一页带、路由翻页不重发。
- `test/review-ack.test.mjs`（+1 条）：看得见就撤得掉（公共记录与管理员）；顺手把登录态那条用例的口径改到新规则。
