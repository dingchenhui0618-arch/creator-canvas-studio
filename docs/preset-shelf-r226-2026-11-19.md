# 对话预设：选好就收起预设库、卡片标出「当前」（r226 / v0.9.210）

2026-11-19。清单第 11 项（UX 续）：接着 r225 的思路，处理「对话预设」这一面。不改接口、不碰上游。

## 结论

1. **「对话预设」选好一个之后，下面 979px 的预设库还在**。这时人要写东西，不是继续挑；
   手机上整页 1717px，输入框和那四张卡一起占了两屏多。现在选完自动收成一行
   （「当前「投放素材变体」+ 换一个预设」），390 宽整页 **1717 → 844**（正好一屏，不用滚）；
   点那一行展开回去还是 1717，换预设 / 编辑 / 删除都在里面。
2. **看不出自己选的是哪一张**。列表加载时会自动选中第一个（服务端的默认值，不是用户挑的），
   但卡片长得一模一样。现在当前那张描边加重、名字旁边多一枚「当前」。

## 边界

- 收起只发生在 ≤900；桌面一直展开三列卡片，行为没变。
- 「换一个预设」只是展开，不会自动滚到库的开头——展开后那一行就在它上面，往下一点就是卡片列表。
- 收起后编辑 / 删除预设要多点一次「换一个预设」；这是为「选完就要写东西」让路的有意取舍。
- 只改前端结构与样式，没有新接口、没动服务端与计费。
