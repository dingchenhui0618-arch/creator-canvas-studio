## 1. 词表口径：A 档 / B 档

扫描器 `scripts/scan-copy.mjs` 把「品牌类」拆成两档，退出码只看 A 档：

- **A 档（必须 0，退出码看它）**：上游厂牌与中转商名 —— `deepseek`、`geteapi`、`seeapi`、`cgcm`、`openai`、`anthropic`、`claude`、`gemini`、`gpt`、`gpt-型号`、`qwen` / 通义、`doubao` / 豆包、`volcengine` / 火山引擎 / 火山方舟、`moonshot`、`zhipu` / `glm-`、`minimax`、`xai`、`grok`、`sora`、`midjourney`、`stable-diffusion`、`nano-banana`、`seedream`、`kling` / 可灵、`hunyuan` / 混元、`ernie` / 文心一言、`codex`、`workbuddy`，以及任何 `xxx-flash` / `xxx-pro` 形式的**内部模型 id**。
- **B 档（只统计，不阻塞）**：产品里本来就在用的自有产品标签 —— `GPT Image N`、`Seedance N`、`Seedream N`、`Kling N`、`Wavision`（列表页、画布节点小字、模型选择器走 `/api/models` 下发的标签）。这些**不算泄露，本轮不改**；A 档匹配前先把它们挖空，所以「GPT Image 2」不会被 `gpt` 规则误报。
- **内部术语（要求 0）**：`上游`、`落盘`、`契约`、`幂等`、`兜底`、`扣费口径`、`token`、`报文`、`SSE`、`CDN`、`缓存策略`、`接口`、`5xx`、`OOM`、内部编号（`r123` / `v0.9.314`）。
- 匹配前恒要挖空：`VisionQA`（自有品牌）与 `127.0.0.1` / `localhost`（版本信息弹窗的「站点」行，是扫描机地址不是产品文案）。

扫描器怎么做：起真服务端（临时数据目录，播种一个账号 / 一个作品 / 一条对话 / 一个带助手成员的房间，**不碰真实 data/**）+ vite dev（真编译 `src`，不跑 build）+ 无头 Chrome；页面内切 `location.hash` 逐屏采集可见文本与 `title` / `aria-label` / `placeholder` / `alt`，含浮层与空状态。覆盖 43 屏（工作台 / 我的作品 / 作品详情 / 爆款雷达 / 模板库 / 聊天室 / 快捷创作 / 对话预设编辑 / 积分记录 / 视觉评审 / 我的资产 / 设置 / 充值 / 无限画布 + 快速跳转 / 账号菜单 / 模型切换 / 版本信息弹窗 / 对话列表抽屉 / 生成设置行 / 对话消息 + 4 张报错页 + 帮助中心 / 素材来源 / 服务条款 / 隐私政策 + 未登录登录页，以及 `GET /api/models`、`GET /api/version` 的返回体）。
