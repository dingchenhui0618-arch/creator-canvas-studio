# r286：登录页是第一屏，别让人凑近屏幕认字（v0.9.268）

日期：2026-11-20 ｜ 前置：r285 / v0.9.267

## 一句话

按 1440 / 390 用无头浏览器量了登录页，一次量出 **12 个问题**：输入框可点区域只有 19px 高、
眼睛按钮 22×22、勾选框 13×13、深色栏次要文字最低 3.32:1，390 宽时登录框整个在首屏之外。
改完再量：**只剩 2 条，都是故意保留的装饰**（巨型水印「VisionQA」，aria-hidden、6% 不透明度、被父层裁掉）。

## 为什么先修这一屏

它是产品的第一屏，也是发版后每个人必看的一屏。而且上一版（r257/r261）把字号抬到 13px 地板时，
**登录页不在那次盘点里**——它的输入框字还是 13px、框里那行 input 自己不占高度（外层 38px，
真正可点的只有一行字那么高，点在上下留白上会掉焦点）。用户说「至少让我看得清楚字是啥」，
这一屏最该先改。

## 改了什么（只动 `src/styles/shell.css`）

1. **可点区域**：`.vq-input input { height: 100% }` —— 外层框多高，可点区域就多高（38 / 44 都一样）。
   这一条对全站所有输入框生效，不只是登录页。
2. **登录页再高一档**：`.vq-login .vq-input { height: 44px }`，输入框文字 13 → **15px**，
   字段标签 13 → **14px**，说明文字 13 → **14px**（这一屏是全站第一屏，值得比地板高一档）。
3. **点得着的控件**：眼睛按钮 22 → **32×32**；勾选框 13 → **24×24**，整行 `min-height: 24px`。
4. **看得清的次要文字**：品牌栏三处半透明白 0.36 / 0.38 / 0.42 → **0.55 / 0.58**，
   在 #111 上分别是 5.5:1 / 6.0:1（原来 3.32 / 3.57 / 4.08，都不到正文要求的 4.5:1）。
5. **手机先给表单**：`@media (max-width: 640px)` 里 `.vq-login-panel { order: 1 }`、
   `.vq-login-brand { order: 2 }`——品牌故事整块挪到表单下面。以前 390 宽要先滚一屏才看得见登录框。

## 守卫

新增 `test/login-a11y.test.mjs`（4 条）：

- 登录页输入框 44px，且 `input` 自己是 `height: 100%`（防「可点区域只剩一行字」退回去）；
- 眼睛按钮 32×32、勾选框 24×24、整行 `min-height: 24px`；
- 品牌栏四处次要文字按 WCAG 公式**现算对比度**，低于 4.5:1 直接失败（不是比字符串，改颜色也会被算）；
- 640 断点里表单的 `order` 必须小于品牌栏。

## 边界

- 登录页之外的其他输入框只吃到「可点区域撑满」与「文字 13 → 14px」两条；各页的框高没动，
  后台 console 那套 36px 输入框的规矩不受影响。
- 巨型水印那条没有改：它是装饰（aria-hidden、6% 不透明度、父层裁切），把它「修」进框里反而破了设计。
  量的问题数因此停在 2，不是没修完。
- 勾选框 24×24 在视觉上比原来重一些；这是按「手指点得着」换的，不是排版走样。
- 这轮只量了登录页这一屏；登录后各页仍是「按需量」，没有一次全站扫。
