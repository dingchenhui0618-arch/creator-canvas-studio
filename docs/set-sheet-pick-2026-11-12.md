# 现场页按镜打印：一天只拍几镜，就只印那几镜（v0.9.7）

一句话：现场页顶栏多了一行「只印 2-4,6」，回车换一版纸；没选中的镜头不出现在纸上。
同一条作品、同一份数据，全部 8 镜印 **A4 3 页**，只印第 2–4、6 镜印 **A4 2 页**。

## 为什么要做

现场页（`/print/projects/<id>/deliverable?only=script`）本来只回答两件事：念什么、拍什么。
但它一次印全部镜头（最多 24 镜）。真实场景里编导一天只拍其中几镜——一张 8 镜的纸还好，
24 镜的纸在现场要一边翻一边找；拍第 3 镜的人也不需要第 8 镜的帧图。

之前的绕法是「打印对话框里缩页面范围」，那是按纸的页数切，不是按镜头切，切出来常常半张卡断在页边。

## 现在怎么用

1. 作品页 → 交付 → 现场页（新标签打开）。
2. 顶栏「只印 [ 2-4,6 ]」，写镜号，回车。留空 = 全部。
3. 顶栏右侧跟着变「印 4 / 8 镜」；纸上抬头下面多一行
   「本张只印第 **2–4、6** 镜（全片 8 镜，未印的 4 镜在作品页看）。」
4. 地址栏同步成 `...&shots=2-4,6`——刷新、收藏、发给同组的人都还是这 4 镜。
5. 交付包里那张 `现场页.html` 双击打开（`file://`）也能改：脚本是几行纯 DOM，不联网、不加依赖。

## 写法

| 写法 | 结果（作品 8 镜） |
| --- | --- |
| `2-4,6` | 2、3、4、6 |
| `2、4，6` | 2、4、6（顿号、全角逗号都认） |
| `1 至 3` | 1、2、3（`-` `–` `~` `至` 都当范围） |
| `7-5` | 5、6、7（写反了按两头夹住，不报错） |
| `99,0,3` | 3（越界的镜号直接丢掉） |
| `abc` / 空 | 印全部；`abc` 时顶栏补一句「没认出这个写法，印全部 8 镜」 |

规则一句话：**认不出的部分不猜、不报错，整条退回「印全部」**。纸不是表单，现场没人愿意先跟输入框斗智斗勇。

## 三个实现决定

1. **卡片全在 DOM 里，没选中的带 `is-off`**（屏幕与纸上都 `display:none`）。
   改选区不重新请求，交付包里也能改；同时服务端先按 URL 把该隐藏的隐藏好——
   关掉脚本或脚本出错，这张纸仍然是对的（渐进增强，不是全靠 JS）。
2. **两份解析同口径**：服务端 `parseShotRange()` 与纸上那几行脚本各有一份，
   因为离线包没法 import 模块。两边用同一批用例钉住（`test/project-set-sheet.test.mjs`）。
3. **口径不动**：段落表仍然全印（8 段一张纸放得下）；交付包里的帧图仍然带全部——
   换一天再拍另外几镜时，那个包还能用，不需要重新导出。

## 实测数字

生产作品 `prj_f38d68c6`（毛衣折叠收纳法，v2，8 镜、8 张帧图，模板 `tpl_5323f485`）：

| 项 | 全部 8 镜 | 只印第 2–4、6 镜 |
| --- | --- | --- |
| 纸上镜头卡 | 8 | 4（02 / 03 / 04 / 06） |
| A4 页数（Chrome `Page.printToPDF`，preferCSSPageSize） | **3** | **2** |
| 文档高度 | 2405px | 1621px |
| 顶栏文案 | 印全部 8 镜 | 印 4 / 8 镜 |
| 地址栏 | `?only=script&tz=480` | `?only=script&tz=480&shots=2-4,6` |

交付包那张纸（`file://`）：控制台 0 异常；把选区从 `2,5` 改成 `1-3` 后可见卡片 2 → 3、
顶栏文案与纸上那行同步；包里只打了 `shot-01.jpg` 时，其余镜头照旧写「没存帧图」，不留打不开的地址；
离线没有「返回作品」链接（那个地址在本机打不开），品牌改用文字。

## 边界（照实写）

- **段落不筛**：只做镜头。8 段以内的段落表一张纸放得下，现场翻页不是问题；真要按段落切再接。
- **封顶仍是 24 镜**：选区只在纸上的前 24 镜里生效（第 26 镜写了也不会印，因为那张纸本来就不印它）。
- **重复镜号**：选区按镜号，同一镜号出现两次会一起印/一起去掉（模板拆解一般不会重复）。
- **帧图不跟着减少**：交付包始终带全部帧图；纸上少印不等于包里少打。
- **交付稿的打印版没有这个控件**：它印全文（时长对账、评审、版本对照、运行记录），没有镜头卡可筛。
