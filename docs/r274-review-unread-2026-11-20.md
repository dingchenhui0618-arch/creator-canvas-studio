# r274 · 评审页：读不到不等于没有，空占位也不等于画面没了（v0.9.256）

2026-11-20。这一轮回到主线的第四站「评审」。产品本身不缺功能，缺的是**说真话**：
两个本该独立的接口被绑在一起，一处失手就把另一处已经读到的结果一起丢掉；
一个本来就没有画面的模板，被写成「画面已经不在了」。

## 一、三个现象

| 看到的话 | 真实情况 |
| --- | --- |
| 评审模型「未配置」，同时「开始评审」点不了 | 只是 /api/review/health 没读到；模型配没配根本不知道 |
| 折叠开关「0 个模板首帧」+「模板库还是空的，先去爆款雷达复刻一条」 | 只是 /api/templates 没读到；库里可能有 26 条 |
| 挑了个没抽到首帧的模板 →「评审时的画面已经不在了」，按钮照样能点 | 从来就没有画面；点下去是一条没有画面的请求 |

## 二、根因

```tsx
// 改前：两条互不相干的接口挤在一个 Promise.all 里
Promise.all([getReviewStatus(), listTemplates({})])
  .then(([health, list]) => { setStatus(health); setTemplates(list.items) })
  .catch(() => undefined)   // ← 任何一条失手，两条结果一起丢，而且不留一句话

<button disabled={running || !status?.model || modelBlocked}>开始评审</button>
// status 还是 null 时 !status?.model 为真 → 永久锁死，标题里写着「未配置」

{picked.preview && !previewBroken ? <img …/> : <div>评审时的画面已经不在了</div>}
// 只有两档：有图 / 「没了」。没抽到首帧的模板（preview 为空）落进第二档
```

评审页另外三处读失败原本都有话（历史、候选、上传），只有这两条没有——所以这一轮不是加功能，
是把同一页里两套标准拉齐，顺便把「画面区只有两档」这条也补上。

## 三、判据（都在 src/domain/review-ready.ts）

| 读到的情况 | 两只胶囊 | 「开始评审」 | 页面上的话 |
| --- | --- | --- | --- |
| 两条都读到、模型可用 | 评审引擎 本地服务 / 平台模型 · 评审模型 可用 | 能点 | 不提 |
| 状态没读到 | 评审引擎 状态没读到 · 评审模型 状态没读到 | **能点**（服务端再判一次，失败原路退回） | 「评审服务状态这次没读到——不是没配置…」+ 重新读取 |
| 两条都没读到 | 同上 | 能点 | 一句话说完，原始原因只有内部版才显示 |
| 读到、模型真没配 | … · 评审模型 未配置 | 点不了，title 写原因 | 不提 |
| 模板库没读到 | 不受影响 | 不受影响 | 开关「模板首帧没读到」，空状态「不是库空了」 |

画面区也从两档拆成三档：

| 挑到的画面 | 画面区 | 按钮 |
| --- | --- | --- |
| 有图、打得开 | 图 + 编号锚点 | 能点 |
| 有来源但打不开（评过） | 「评审时的画面已经不在了」+ 结论与锚点仍然有效 | 能点 |
| 有来源但打不开（没评过） | 「这张图打不开」 | 能点（说清模型多半看不到） |
| 压根没有画面 | 「这一条没有可评的画面」+ 换模板或自己传一张 | **点不了**，title 写原因 |

## 四、验收：假上游 + 筛选代理，0 次上游调用

做法：临时实例（8802）+ 一个只在本机用的代理（8801）——按 fail.json 让指定接口返回 500，其余原样转发；
无头 Chrome 用真实 cookie 打开 /?v=N#/review（每次换 query，免得同文档跳转不重新拉数据）。

| 场景 | 结果 |
| --- | --- |
| 模板库失手、状态正常 | 胶囊仍是「平台模型 · 可用」；提醒条「模板库这次也没读到，左栏一帧也没列…」；开关「模板首帧没读到」；全文没有「还是空的」「未配置」 |
| 状态失手、模板库正常 | 胶囊「状态没读到 · 状态没读到」；提醒条「不是没配置：可以直接点「开始评审」试一次…」；挑一张首帧后**开始评审可点**（disabled=false） |
| 点「重新读取」（不刷新、不重登） | 提醒条消失，胶囊回到「平台模型 · 可用」，开关回到「4 个模板首帧」 |
| 挑一个没抽到首帧的模板 | 画面区「这一条没有可评的画面」；**开始评审 disabled**，title「这次挑的画面是空的：换一个有首帧的模板，或自己传一张图」 |
| 390 宽重新载入 | 提醒条仍在，「重新读取」**44×44**，scrollWidth == innerWidth == 390 |

## 五、边界

- 「没读到就放行」只用于**能不能评**这一件事：真没配模型时服务端会回错，页面照原话显示，不扣积分。
- 画面区第三档（打不开）仍允许点评审：浏览器加载不了不等于服务端取不到那张图，点了以服务端为准。
- 模板库读不到时左栏只有「传一张自己的图」和图片地址两个入口——模板那一列确实没有东西可列。
- 只改评审页与它自己的判据模块；服务端 0 改动，/api/review/health 与 /api/templates 的返回形状没动。
