# 沉淀完能直接打开它，模板库卡片自己写评审结论（r253 / v0.9.236）

日期：2026-11-19。上一轮（r252）把「评审通过 → 存成模板」接上了，但接完之后还断两截：

1. 存完只留一句「在模板库里能查到」，人还要自己翻到模板库、找到那一条；
2. 模板库里这条新模板的卡片和一条没评过的模板长得一样，「评审通过」只在点开抽屉后才看得到。

这一轮把这两截接上，不改数据契约：模板原本就带着 `review { verdict, at, issueCount }` 快照（r252 落的），
卡片只是把已有的字段显示出来。

## 改了什么

| # | 位置 | 以前 | 现在 |
| --- | --- | --- | --- |
| 1 | 评审结果页存完那一行 | 「已存成模板《X》（3 段 · 2 镜 · 评审通过），在模板库里能查到。」 | 同一句去掉「在模板库里能查到」，后面跟一个 **看这条模板 →**，点了就是 `#/templates/<新模板 id>` |
| 2 | 模板库卡片 | 只有「N 段脚本 · N 个分镜 · N 条作品在用」 | 多一格 **评审通过**（绿字），没有评审记录的模板不多这一格 |
| 3 | 那一行小字字号 | 13px | 14px，跟结论正文一致（用户提过「字有点小」） |

「看这条模板」用的是模板库已有的抽屉地址（`#/templates/<id>`），不新开页面、不新加接口；
新模板 id 直接取 `POST /api/projects/:id/template` 回来那份 `template.id`，不靠再查一次列表猜。

## 口径

| 问题 | 口径 |
| --- | --- |
| 什么时候给「看这条模板」 | 只有存成功（status=done）且拿到 id 时；存失败的行只有原话，不给链接 |
| 存完还留「存成模板」按钮吗 | 不留（r252 起就不留）：同一版重复存只会多出一条一样的模板 |
| 卡片上「评审通过」从哪来 | 模板上的 `review.verdict` 决定文案与颜色：pass 绿、needs_review 黄、fail 红；没有 `review` 就不显示 |
| 历史评审记录里有这个出口吗 | 没有：历史记录只读，那一条本来就没有「刚存完」这回事 |
| 点「看这条模板」会打断当前评审吗 | 不会丢数据：评审结论已经落库，地址换到模板抽屉，后退回得去 |

## 边界

- 只改界面与样式：服务端零改动（模板的 `review` 快照 r252 就在，卡片只是显示它）。
- 卡片上的结论是**存下来那一刻**的快照，之后作品重评不会改它；要更新得再存一条。
- 「看这条模板」直接换地址，不会把评审页留在后台（刷新、后退按地址重建，评审结论已在库里）。
- 没有「在这条模板上再评一次」的入口：要评得先「用这条作品」把它变回一条作品。
- 探针只验了 pass 一种结论；needs_review / fail 的颜色只在单测里覆盖（模板接口只在有评审时落快照）。
