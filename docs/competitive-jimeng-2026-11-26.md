## ① 定位与目标用户

- 官方定位「一站式智能创作平台／即刻造梦」，主导航是：文生图、视频生成、短剧工作室、智能画布、探索、未来影像计划、价格 [S1]。
- 应用内一级入口：创作、探索、画布、AI工具、资产和主体、对话；短剧工作室与营销工作室标 New [S3]。
- 账号即剪映账号，跨即梦/剪映共享昵称、头像、简介、手机号 [S5]。
- 用户协议写明「主要适用人群是成年人」，未满 18 周岁需监护人陪同 [S5]。
- 已就 5 个模型与算法做备案公示（豆包大模型、文生图、视频生成、音乐、语音）[S7]。

判断：即梦是「工具 + 内容社区 + 订阅」的 C 端产品，卖的是「一条能用的素材」；它没有项目、评审、交付、多角色协作这一层，用户拿走后要靠剪映收尾。

## ② 输入与产出形态

- 输入：文本；图片参考 0-30 张；视频参考 0-10 个；音频参考 0-10 段（Seedance 2.5 可只传音频，2.0 系列必须至少配图或视频）[S8]。
- 产出：图片（文生图/图生图/组图/图层拆分）、视频（有声或无声）、短剧（短剧工作室 + 短剧 Agent）、音乐与语音（备案含豆包音乐、豆包语音模型）[S1][S3][S7]。
- 视频三种互斥场景：图生视频-首帧、图生视频-首尾帧、全模态参考生视频，官方明写不可混用 [S8]。
- 没有「长视频」入口：单次上限 30 秒，长度靠「延长视频」叠加 [S8][S9]。
- 短剧工作室是独立产品面，带自己的 Agent 对话入口 [S3]。

判断：即梦的产出单位是「一条 4-30 秒素材或一张图」，不是「一个可交付的项目」。它把「成片」的活儿留给了剪映，这既是省事也是它的边界。

## ④ 编辑与二次加工

- 智能画布：AI 拼图生成、局部重绘、一键扩图、图像消除、抠图、多图层编辑、精细化控制 [S1]。
- 视频侧有「编辑视频」「延长视频」，且任务结果会返回视频尾帧图 [S8][S9]。
- 图片侧有图层拆分（1 张底图 + 最多 16 个图层）与交互编辑（坐标、框选、箭头指定位置）[S10]。
- 视频补帧、视频高清、智能超清（4K，高级档起 4K/8K）为会员权益 [S2]。
- 分镜、口播、字幕、BGM 的官方功能页：未见 → **未核实**（不把「短剧工作室」直接当成分镜编辑器）。
- 导出剪映：只有第三方教程讲「即梦生成→剪映成片」[S16, C]，官方无工程包/剪映工程导出说明 → **未核实**。

判断：即梦的编辑是「素材级精修」——把一张图或一段视频改到能用；它不做叙事结构，分镜表、口播稿、字幕轴这些还是人（或我们）的活。

## ⑤ Agent / 工作流 / 自动化

- 「对话」为一级入口；短剧工作室首页直接写「和 短剧 Agent 聊聊创作想法」[S3]。
- 会员条款明写「无限生成…限即梦网页版的图片生成（**非 Agent**）、画布模式使用…每次仅限 1 个并发，**不支持 CLI/MCP**」——反证 Agent 模式、CLI、MCP 三条通道都存在 [S2]。
- 对外 API：火山方舟视频生成与图片生成（doubao-seedance-*、doubao-seedream-*），任务式异步 [S8][S10]。
- 开通门槛：账户余额 >200 元，或买 200 元档以上节省计划，或有资源包余量 [S8]。
- 即梦侧：超级会员才有「API服务购买」，API 额度需单独购买、与会员积分不通用 [S2]。
- 工作流市场、节点编排、GPU 租用：官方无对应页面证据 → **未核实**（火山引擎 GPU 实例是另一条产品线，不算即梦能力）。

判断：即梦把自动化做成「Agent 对话 + 任务 API」，不做「节点画布」。它赌的是自然语言编排，我们赌的是可视化节点，两条路各有代价。

## ⑥ 素材与资产

- 「资产和主体」是一级入口 [S3]。
- 参考素材上限（Seedance 2.5）：30 张图 + 10 个视频 + 10 段音频，三类总时长各不超过 30 秒；2.0 系列降到 9 图/3 视频/3 音频、总长 15 秒 [S8]。
- 素材以素材 ID 形式复用（asset://ID），并有「素材 & 虚拟人像库」[S8]。
- 数字人：OmniHuman 1.5 用「单张图片 + 音频」驱动，支持多人场景指定说话人，多人唱歌/说话需主体检测服务返回 mask_url [S11]；会员权益里直接列「视频对口型」[S2]。
- 含真人脸的参考图/视频不能直接上传；官方给三条替代：本账号近 30 天模型产出的含人脸视频、预置虚拟人像、已授权真人素材 [S8]。
- 首帧、尾帧、参考图是有明确 role 字段的独立场景 [S8]。

判断：即梦的资产层是「可复用参考素材 + 官方虚拟人像」，合规压得很实——它不是不让你用真人，是把真人素材的来源收进自己的资产库。

## ⑦ 模板与社区

- 「探索」社区是作品流 + 作者名，内容形如「AI 原创作品《我在国外捉鬼》」[S4]。
- 「同款」写进了用户协议 9.6：他人可对你的发布内容「做同款、用灵感/用作参考图、其他 AI 内容生成」并再发布、复制、下载 [S5]。
- 创作者激励：未来影像计划为官方活动页 [S13]；首期挑战赛设「价值 20 万元创意基金」[S14, B]。
- 2026 创作者成长计划：参与即得积分、优质短片最高 28888 积分、爆款 2000 元现金、优异者开星图白名单接商单 [S15, B]。
- 参数化模板库（像我们那种可复用、可复刻的模板）：官方无「模板」功能页证据 → **未核实**。

判断：即梦的「同款」是**内容级复制**——把别人的成品当参考图再生成一遍，靠用户协议授权；不是**参数级模板**。它靠官方比赛和商单白名单做创作者运营，不靠模板分成。

## ⑩ 能直接借鉴的点 / 必须避开的坑

可直接借鉴：

1. **公开单秒价**，不只给积分——用户能自己算一条多少钱，减少「扣了多少」的客服。
2. **积分换算率写在档位卡上**（¥10 = 192~328 积分），档位越高越划算，天然引导升级。
3. **阶梯递减单价**（¥0.57 → ¥0.16/秒）用价格差驱动升级，比功能阉割温和。
4. **「无限生成」写成一组限定**：限模型、限分辨率、限并发、限期限、排除 Agent/CLI/MCP——促销可控、成本可算。
5. **首帧/首尾帧/全模态参考作为互斥场景**，UI 上不混，参数强校验 + 提示词弱校验双通道 [S8]。
6. **返回尾帧图**——天然支持「接着做下一镜」，是低成本的分镜串联。
7. **图层拆分（1 底图 + ≤16 图层）** 直接对接设计工具，比「生成一张图」值钱。
8. **「同款」写进用户协议**，而不是只做一个按钮——内容级复用的授权先立住。
9. **活动规则一页写清**：期限、对象、折扣范围、赠送范围、不可退款例外 [S2]。
10. **合规骨架**：模型备案公示页 + AI 标识 + 接入方回链，三件套可以直接抄结构。

必须避开的坑：

1. **促销价与续费价差距过大**（¥393 首年 / ¥659 次年；¥7019 / ¥15598），不显式提示就是投诉源。
2. **「无限」带五六个限定**（1 次/账号、1 并发、不支持 CLI/MCP、非 Agent、仅网页版），容易被读成「随便用」。
3. **积分有效期 29 天 + 延期卡**，规则复杂度已经需要单独的「积分详情-积分延期」页面 [S1]。
4. **失败是否退积分官方不说**，用户只能找客服；这正是我们可以做差异的地方。
5. **单账号禁止共享**，想接团队协作必须重谈协议，别指望「加个子账号」。
6. **生成内容授予平台推广/广告/营销再许可** [S5 9.4]——给客户交付素材时要看清这一条。
7. **真人脸参考被限制**，数字人只能走平台虚拟人像或已授权素材 [S8]，做「客户本人出镜」的方案要提前设计。
8. **30 秒是上限不是常态**，分镜、口播、字幕仍要自己拼，别把它当「一键成片」。
