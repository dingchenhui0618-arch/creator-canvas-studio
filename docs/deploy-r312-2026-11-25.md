## 包里有什么

- `server/asset-ref.mjs`（新）：引用格式 `asst_<时间戳>_<十六进制>:<槽位>`、归属校验、读字节、压到长边 1024 的 JPEG；读不到一律 `400 ASSET_REF_MISSING`。

- `server/routes/media-gen.mjs`：`assets` 数组接受 `asst_…:slot` 或 `asset:asst_…:slot`，按 1 张参考图算进 `mode` 张数校验，元数据记成 `asset:…`。

## 怎么发的

走仓库既有发布链路（不重跑 `install.sh`，那会连 nginx 配置一起重写）：

1. 本地 `npm run build`（`tsc -b` + vite build）——CI 45529670570 已在同一 commit 上构建过同一份产物，入口 hash `index-CQXLYfZL.js` 一致；
2. 打包 `tar -czf vq-r312.tgz dist server scripts package.json deploy`（12.6 MB / 676 项；扫过包内没有 `.env`、`auth.db`、私钥或凭据文件，命中的只有文件名里带 key 的源码）；
3. `scp` 到 `/tmp/vqdeploy-r312.tgz`，解开到 `/tmp/vqstage-r312`；
4. `bash /tmp/vqstage-r312/scripts/deploy.sh /tmp/vqdeploy-r312.tgz 20261125-1325-r312assets` —— 先给当前版本打快照，再替换 `dist / server / scripts / package.json`（`data` 不动），重启两个服务并自检健康。
