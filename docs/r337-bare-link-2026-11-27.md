# r337 · 第五层：非按钮的可点表面（链接 / 行 / 卡片），划过毫无反馈的 1 张 → 0（v0.9.310）

## 一、结论

四层交互状态（按下 r331–r334、划过按钮 r335、键盘焦点 r336）都清零之后，剩下的盲区是**不是按钮的那一片**：
链接、可点行、整卡。它们没法用前面那套测法——按下那一层必须真按，而**链接一按就跳页**，所以链接、可点行、
整卡从来没被量过。

这一轮把「划过」扩到这一类（第五层，`--links`），只划过、绝不按下。全站 11 趟 / 1440×1000 上一次量到
**9 张非按钮表面**，其中**1 张划过毫无反馈**（模板库详情抽屉里的「打开原视频」，一个没挂类的裸 `<a>`，
有 `cursor: pointer`、却一条 `:hover` 规则都没有）。补齐之后 **1 → 0**，划过有反馈 **8 → 9**。

「9 张」这个数字本身就是结论的一半：**这个站几乎不剩非按钮的可点表面**（可点的东西基本都是 `<button>`，
已经由前四层管着）。真正要修的不是这一张，而是它背后那一类：全站 **9 处裸 `<a>`**（抽屉、分享页、复刻弹窗、
帮助页、作品页、房间页、后台报告、Markdown 正文）。所以修法不是给这一张单独加样式，而是给「没挂类的链接」
一条**底线**——9 处一次归队，以后新加的裸链接也自动落在这一层里。

## 三、量具自己错了第三处（形状与前两处一样）

前面两处自我纠正都是同一个形状：**一条变化看起来是反馈，其实是别的值推导出来的**。r335 是
`border-color`（边框宽度全 0 时它就是 currentColor），r336 是 `outline-color`（环没画出来时同理），
这一次是 `text-decoration-color`：`.vq-link` 划过只改 `color`，下划线的颜色跟着字色一起变，
被第一版量成「变了、但没声明过渡 = 硬切」，工作台一屏 3 张面全中招。

判据与前面同一条路子，但这次用的是**值对不对得上**，不靠猜：下划线的 from→to 与 `color` 的 from→to
一模一样 → 它就是 currentColor 的另一种写法；或者这一张面压根没画线（`text-decoration-line: none`）→
没有线可上色。两种都记成 derived，不进 `changed`、不进硬切。

第二处是量具自己的**取景错误**：第一版把 `label[for]` 也当成「可点表面」，于是在后台运营位那一屏量到 20 张
面全是 `<label>`（全站的 26 张「看不出变化」里 20 张是它）。label 是控件的说明文字，点它是「把焦点送到那一格」，
划过给反馈反而是噪音——已经整类摘掉。

还有一条与判据有关的：`text-underline-offset` 在 `auto ↔ 3px` 之间是**离散**的（不补间），
所以它算反馈、不算硬切。r334 给 `.vq-link` 声明的那条 `text-underline-offset` 过渡因此实际上不会动——
下划线出现/消失本来也不补间，手感上没有差别，这一轮只是把这件事量清楚了，没去动 r334 那条声明
（静态门禁要求它存在，见第五节）。

## 四、补了什么

1. **裸链接的底线**（`shell.css`）：`a:not([class])` 一条过渡（`color` / `background-color` /
   `text-decoration-color` / `text-underline-offset`），`:hover` 补下划线与 3px 下移，`:active` 压一层底
   （与 `.vq-link` 同一套口径：只划过有反馈、按下去没反应，手感是半截的）。
   `:not([class])` 是关键——`.vq-link` 与从 `<a>` 渲染出来的 `.vq-button` 都挂着类，一点也不受影响。
   rest 的颜色仍由所在容器说了算（`.drawer-source a` / `.share-source a` / `.replicate-foot-note a` 各自一档）。
2. **外链图标划过顶一下**：`.drawer-source a:hover svg` / `.share-source a:hover svg` 右上 2px / 120ms，
   与作品流卡片那颗箭头同一套手感；「减弱动态效果」时单独一段 `transform: none`（**单独一段**是有意的，
   前面那段是 r331 那五个家族的，`press-shell.test.mjs` 的反证锚在它的结尾，往里塞新规则会把反证改成永远不触发）。

一处没动：`ReplicateModal` 的「打开原视频」图标在 `<a>` 外面（是兄弟节点），`a:hover svg` 选不到它，
这一处只吃了第 1 条的下划线反馈。
