## 二、主要功能（申请表「软件主要功能」栏，可直接粘贴）

VisionQA 是面向内容创作团队的多智能体会话与画布创作平台，由会话、画布、资产三个层次构成。

会话层以「快捷创作」为统一入口，一个输入框内可切换对话、图片、视频三种方式；每个自建智能体可配置职责说明、知识条目与默认模型，对话按会话保存最近上下文（8 条 / 6000 字），回复中的结构化草稿可一键存为模板或送到画布。

画布层提供两种工作面：「工作流」用输入、大模型、知识库、工具、条件、输出六类节点把一次创作串成可执行流程，服务端按拓扑序执行并逐节点记录耗时与输出；「无限画布」自由摆放素材、生成结果与笔记，出图出视频在画布上直接完成，两块画布通过短时票据实现账号互通。

资产层包括作品、版本、模板库与交付档案：一条内容对应一件作品，每次修改形成一个可对照的版本，评审结论、交付包与回执均挂在具体版本上。视觉评审按七个维度给出「通过 / 需人工确认 / 不通过」三种结论，每条判断必须带画面区域的像素锚点，给不出证据的写入「无法判断」；交付时把脚本、分镜、帧图与评审对照封存为 zip，写入逐条 CRC32 与整包 SHA-256，收包人可在本地校验并回执。

平台同时提供账号与会话管理、积分与计费、后台的密钥池与模型路由、告警与存储守护、运行审计，以及桌面端本地工作区（在本机读写文件、执行命令，写操作逐次审批）。

## 三、技术特点（申请表「技术特点」栏，可直接粘贴）

1. **证据化评审**：结论只有三种，每条判断绑定相对坐标锚点，无锚点即降级；评审通道可降级并在结果中写明实际通道，不把本地模型结果冒充专用服务结果。
2. **双画布分工**：节点编排画布负责可复跑的执行链（连线四重校验、拓扑执行、逐节点留痕），自由画布负责素材摆放与即时生成，二者通过 HS256 短时票据互通身份。
3. **多智能体会话**：智能体带职责与知识条目，会话上下文服务端截断，结构化草稿以约定 JSON 交换，可直接沉淀为模板或画布节点。
4. **可校验交付**：交付包封存时写入逐条 CRC32 与整包 SHA-256，包内附本地校验页，生成回执并与封存包逐项比对。
5. **账号隔离与安全**：scrypt 口令哈希、会话只存哈希、Origin 校验、登录限流、按账号过滤数据；上游密钥加密保存、界面只显掩码。
6. **可降级运行**：模型、生成通道、检索、邮件、短信、外部画布均未配置时不伪造结果，界面如实说明并保留其余功能。

（约 330 字）

判断标准只有一条：**这个软件以后由谁商业化。**

- 纯个人作品（自用、开源、个人接单、个人产品）→ 个人，最省事，现在就这么办；
- 由公司运营，或打算申补贴 / 融资 / 投标 → 现在直接写单位，省一次转让；
- 现在拿不准 → 个人登记，同时与公司签一份著作权转让或独占许可协议备用；将来真要用再办转让登记。
