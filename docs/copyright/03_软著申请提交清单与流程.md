## 二、在线登记操作顺序

> **已实测的入口与前置条件（2026-11-18）**：登记系统入口是 `https://register.ccopyright.com.cn/registration.html#/registerSoft`，本次业务为 **R11 计算机软件著作权登记申请**。直接访问 `register.ccopyright.com.cn` 根域名会被 openresty 回 403，必须从 `www.ccopyright.com.cn` 首页点「软件登记」进入。未登录时点「立即登记」就地弹出登录框（个人用户／机构 × 密码登录／验证码登录），系统提示「原系统已有账号无需重新注册可直接登录」。个人账号须先完成实名认证，涉及身份证与人脸活体核验，只能本人操作；账号密码与短信验证码不由自动化工具代输。

1. **注册与实名**：在中国版权保护中心登记系统注册账号，完成实名认证（个人身份证 / 单位营业执照与经办人信息）。
   - **硬性卡点（实测）**：实名认证提交后状态为「我们将在 1-3 个工作日内审核」，审核期间点 R11「立即登记」只弹「您已提交实名认证申请」提示，**无法建单**。也就是说提交材料的时间要以审核通过为准，排期时把 1-3 个工作日算进去。
2. **新建申请**：选择「计算机软件著作权登记」，按 `00_软著申请信息汇总.md` 的字段逐项填写软件全称、简称、版本号、开发完成日期、发表状态、开发方式、权利取得方式、权利范围、软硬件环境、编程语言、源程序量、主要功能与技术特点。
3. **上传鉴别材料**：源程序 PDF（60 页）与说明书 PDF（29 页）分别上传；文件命名建议与内容一致，避免使用临时名或版本冲突名。
4. **核对一致性**：软件全称、版本号在申请表、源程序页眉、说明书页眉三处必须完全一致（含空格与全半角）。
5. **提交与签章**：确认无误后提交；按系统要求打印申请表签字或加盖公章，或使用电子签章。
6. **受理与审查**：受理后进入审查；若收到补正通知，按通知逐条修改并在期限内重新提交，不要只改一处。
7. **领取证书**：审查通过后下载电子证书或按通知领取纸质证书。

## 五、常见补正原因与规避

| 补正原因 | 本套材料的处理 |
| --- | --- |
| 名称不一致（申请表 / 页眉 / 封面） | 三处统一为「VisionQA 多智能体会话画布创作平台」，提交前再用核对表逐项确认 |
| 源程序页数不足或每页行数不足 | 固定 50 行/页，共 60 页，PDF 逐页核对 |
| 源程序含大量空行、注释或非代码内容 | 只保留非空代码行，文件之间以一行文件路径注释分隔 |
| 说明书过于简略或没有截图 | 11 章说明功能、环境、架构、操作与安全，附真实界面截图 |
| 软件功能描述与实际不符 | 功能描述逐条对应已实现模块，未实现或未配置的能力在说明书中写明边界 |
| 版本号与开发完成日期矛盾 | 开发完成日期取最后一次提交时间；说明书附录 C 说明对外版本与内部构建号的关系 |
| 上传文件损坏或无法打开 | 提交前用 PDF 阅读器打开确认页数与文字可选 |

## 六、命名规范

- 文件名不带「最终版」「修改版」「副本」等词，避免审查时与提交记录混淆。
- 推荐格式：`01_源程序文档_<软件全称>_<版本号>.pdf`、`02_软件说明书_<软件全称>_<版本号>.pdf`。
- 软件全称中的空格在文件名里可省略（本目录即省略），但文档页眉与申请表中必须保留规范写法。

## 七、材料重新生成

本目录的 `tools/` 保留可复现脚本，改名称或版本号后重跑即可：

| 命令 | 作用 |
| --- | --- |
| `python tools/stats.py` | 重新统计源码文件数与行数，输出 code-stats.csv / .json |
| `python tools/gen_source_doc.py` | 重新生成 60 页源程序文档（修改脚本顶部的 SW_NAME / SW_VER） |
| `python tools/gen_manual_full.py` | 重新生成说明书 docx（正文在 manual_body1.py / manual_body2.py） |
| `python tools/pdf_check.py` | 核对源程序 PDF 的页数与每页行数 |

改名时必须同步修改：`gen_source_doc.py` 的 SW_NAME / SW_VER、`gen_manual_docx.py` 的 SW_NAME / SW_VER、本目录三份 Markdown 中的名称，并重新导出两份 PDF。

## 九、证据边界（提交材料不写、但内部要清楚）

- 说明书中的界面截图取自真实运行界面（生产站点与本机构建），但截图中的账号、作品与数据为测试数据，不代表客户案例。
- 截图对应的内部构建号不同（0.9.139～0.9.186），界面在版本间有细节调整，不影响功能描述；对外版本统一为 V1.0。
- 软件未做代码签名，桌面安装包由用户自行构建；申请材料不宣称已签名或已接入自动更新。
- 模型准确率、性能指标未在材料中给出结论性数字，避免与实际测试条件不符。
