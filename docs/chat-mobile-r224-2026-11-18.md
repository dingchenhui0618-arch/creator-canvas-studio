# 手机端第二轮：提示条可关、回答里的表格改成逐行卡片（r224 / v0.9.208）

2026-11-18。承接 r223（手机输入框 201 → 148px）继续处理清单里的第 8、9 项，顺带修掉两处窄屏看得见的毛病。
本轮不起真实上游调用：全部改动只碰前端样式、提示文案与一处纯函数；验证用本机临时实例 + 手写会话记录 + 无头 Edge。

## 结论

1. **「这是一个桌面工作台」这条提示以前每页顶 71px、翻十页看十遍**。现在第一次看得见，右侧多一个 ×，
   点过之后这台浏览器不再出现（记在 `vq_mobile_note_seen`）。390 宽下一条 57px，320 宽 77px。
2. **回答里的 4 列表格在 390 宽每列只剩 2～3 个字**（「对比前后，右上角小窗放原图」被切成六行，
   数字和时长孤零零立着）。现在 ≤560 改成一行一张小卡片，表头变成每格前面的小标签：
   「镜号 1 / 时长 0-3s / 画面 … / 目的 …」，逐行读下来就是一张分镜表。桌面 >560 仍是原来的表格。
3. 顺带修两处：320 宽「对话 / 图片 / 视频」三枚页签各折成竖排两字（去掉图标让标签横排）；
   余额行一直显示「每次 1」没单位（改成「每次 1 积分」，桌面同样生效）。

## 边界

- 提示条的「记住」是**浏览器级**，不是按账号：换浏览器 / 清掉站点数据会再出现一次。隐私模式下写不进去，
  下次照常显示（不假装记住）。
- 窄屏卡片把一张 6 行表从 581px 拉到 820px；行数越多整段越长，需要往下翻。超过 6 列的宽表会更长，
  本轮没做「只显示前几列」之类取舍。
- 卡片的标签直接用表头原文：表头为空（Markdown 里 `| |`）时那一格不显示标签，只留值。
- 只改前端样式、提示语与一个纯函数；没有新接口、没动服务端、没动计费。
- 320 宽页签去掉图标是为了横排读得顺，代价是少一层图形提示（标签仍在）。
