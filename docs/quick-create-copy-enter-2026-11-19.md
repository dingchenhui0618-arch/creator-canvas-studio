# 快捷创作：Enter 直接发、回答一键复制、会话被腾位置要说出来（r247 / v0.9.230）

## 结论

这一轮补的是「一页 DeepSeek」最容易被老用户第一分钟就撞上的三处：

1. **Enter 发送，Shift + Enter 换行**（输入法组词时按 Enter 是选字，不发送）。
   以前只有 Ctrl + Enter 能发，从别的对话页过来的人打完字按 Enter 会以为平台没反应。
2. **每段回答一键复制**：复制的是模型原文排成的纯文本，粘进剪辑软件 / 文档里不带 `**` 和 `|`。
   这个产品的回答经常是分镜表和脚本文本，拿不走等于没用。
3. **会话列表满 30 条时，被腾掉的是哪一条要明确说出来**。
   以前服务端悄悄删掉最早一条，用户只会发现「昨天那条长对话不见了」。

顺带把对话页的元信息行（模型名 / 耗时 / 时间）、余额与提示行从 11–12px 抬到 13px：
用户反复说过「字太小，至少让我看清是什么」，这行原来是全页唯一还在 11px 的地方。

## 改动与契约

| 位置 | 改动 |
| --- | --- |
| `src/components/QuickChat.tsx` | `onKeyDown`：Enter 发送（`isComposing` 时不发）、Shift + Enter 换行；回答行尾加「复制 / 已复制」；创建会话后若 `retired` 有值就 toast |
| `src/lib/markdown-parse.ts` | 新增 `markdownPlainText()`：标题去 `#`、加粗去 `**`、表格转制表符、列表保留 `·` / `1.`、代码块保留缩进、链接留「标题 地址」、分隔线丢弃 |
| `src/styles/agents.css` | `.qc-copy`（24px 桌面 / 32px 手机，13px）；元信息行允许换行且不拆词；`.qc-hint`、`.qc-credit`、`.qc-msg-meta` 抬到 13px |
| `server/chat-store.mjs` | `createConversation()` 在腾位置时回传 `retired: { id, title }`（不写进会话文件，只在这次响应里） |
| `src/api/chat.ts` | `ChatConversation.retired?` |

复制口径（写死在单测里）：屏幕上渲染的是排版，剪贴板里要的是字——
表格留成制表符分隔，粘到 Excel / 飞书表格里能直接成列；代码块保留缩进；
`---` 分隔线不进剪贴板（它只是视觉分段）；不安全的链接地址在解析阶段就已经不是链接，复制时按原文出现。

## 验证

### 单测（node:test）

| 用例 | 断言 |
| --- | --- |
| 复制成纯文本 | 结果里没有 `**`、`##`、`\| ---`；有 `口播分镜`、`先说结论：…`、`· 第一镜：开场钩子`、`1\t0-3s`、`  const b = 2`（缩进在）、`参考：一篇 https://example.com/x`；没有单独一行 `---` |
| 空输入 | `''` 与只有分隔线都返回空串，不吐一串空行 |
| 会话满了要说话 | 建满 30 条时每条都不带 `retired`；第 31 条返回 `{ id, title: '老会话 0' }`，那条文件真的没了，列表仍是 30，且 `retired` 不会被当成会话字段写进文件 |

### 端到端（本机临时实例 + 无头 Edge）

| 验的东西 | 结果 |
| --- | --- |
| 复制回答 | 按钮 58×24、点完变「已复制」；读回剪贴板 250 字，**没有 `**`**、表格是制表符、`const hook = …` 与两空格缩进都在 |
| Enter 发送 | 输入框内容清空、这条消息出现在对话里（`draft: ''`，`userBubbles: 1`，`last: 这次用 Enter 发送`） |
| Shift + Enter | 没有发送（`userMsgs` 不变），走默认换行 |
| 满 30 条 | 列表 30 条时新建第 31 条：toast「会话列表满了：最早那条「这次用 Enter 发送」已经挪掉（最多 30 条）」，列表仍是 30 |

> 本轮 0 次真实上游调用：临时实例没有可用的模型 Key，发送那一步很快就以 403 失败并退回积分，
> 这正好也覆盖了「失败时界面说人话」的老路径。没有生图 / 生视频 / 检索调用。

| 宽度 | 小字 < 13px | 点按区 < 40px | 内容溢出 | 整页宽度 |
| --- | --- | --- | --- | --- |
| 390 | **0** | 1（正文里的行内链接 90×19） | 0 | 390 = 390 |

## 边界（说清楚，不装作都做到了）

- **粘贴后换行风格由浏览器决定**：剪贴板里是 `\r\n`（Windows），不是 `\n`。
- **复制不含图片和附件**：只复制回答的文字；带的图、读过的网页和搜到的来源不在剪贴板里。
- **剪贴板可能被浏览器拒**：非安全上下文或用户关掉权限时会 toast「这个浏览器不让网页写剪贴板」，
  不会假装复制成功。
- **腾位置是真删**：列表满 30 条后，最早那条的会话文件会被删除（有提示，但不可恢复）。
  没有做归档 / 回收站。
- **Enter 发送在手机上**：软键盘上的「换行」键等于 Enter，会直接发送；要换行得用 Shift + Enter
  或长按换行——这一点没法在移动端区分，README 与提示行都写明了。
- 元信息行只抬到 13px，没有继续往上（它是一行辅助信息，再大就比正文还抢眼）。
