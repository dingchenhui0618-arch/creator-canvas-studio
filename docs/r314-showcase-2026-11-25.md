# 工作台「做出来是什么样」：五条真实示例上墙（r314，2026-11-25）

结论：工作台在「平台能做什么」之后加了一块**效果示例**，五张竖版卡都是平台的真实产出——
两张成图原图 + 三条 15 秒片的关键帧；下面是「我的作品」，仍然只放账号里的真封面与首帧，
一条都没有时不占一屏。示例区是静态数据，不发任何请求。

## 为什么做

用户原话（r313 九件事之四）：「首页工作台调整 这里相当于一个介绍的功能能力 以及展示我们平台
都能做到一些什么样的效果能力 …… 你可以挑些这里的作品放进去」。r313 只有能力卡 + 账号内的作品墙，
新账号打开是一片「还没有」，说服力全压在那四张文字卡上。

素材来源是用户给的飞书文档（`快捷创作精选作品`，Wiki 节点 `RnUmwRCWsiIre6kexIEce72onTf`）。
它之前是登录墙，r314 用户把它公开之后改走**用户自己的浏览器会话**取图：
Kimi WebBridge 打开页面 → `Network.getCookies` 拿 feishu 域 Cookie → curl 带 Cookie 下原图/原视频
（`internal-api-drive-stream.feishu.cn` 直连 401，必须带会话）→ ffmpeg 抽帧、等比缩到宽 720。

## 边界与取舍

- **示例是平台已产出的作品，不是账号数据**：卡下方明确写了这一句，避免和「我的作品」混为一谈。
- **不点开**：示例卡只展示，不挂跳转——没有对应的作品实体，做成可点会跳到空页面。
  入口在右上角「用同样的方法做一条」，去快捷创作。
- **不动「我的作品」的口径**：仍然只认 `/media`、`/api` 站内素材，外链封面不上墙。
- 五张图共 564 KB，随 `public/` 进构建产物（不打 hash，换图保持同名）。
- 本轮 0 次真实上游调用、¥0；没有改任何服务端接口与数据。
