# 小屏收口：页头 445px 空白、顶栏顶出视口（v0.9.6，2026-11-12）

结论：**产品结构没动，这一轮只修「手机上打开是坏的」**。9 个路由 × 390 / 480 / 1440 三档全部实测：
文档与内容层的横向滚动都是 0，控制台异常 0；同时把全站 102 处随手写的间距收回 4/8 栅格、
23 处 10px 小字升到 11px，并给这两类问题加了会红的测试。

## 1. 怎么发现的

不是走查「觉得哪里不好看」，而是先量：用无头 Chrome 按 390 / 480 / 1440 打开生产站的 9 个路由，
统计四类数字——文档 `scrollWidth` 与 `clientWidth` 的差、每个元素的 `right` 有没有超出视口、
`font-size` 直方图、`padding / margin / gap` 里不在 4 的倍数上的值。第一遍就出了四条：

| 路由 @390 | 文档宽 / 视口 | 页头高 | 备注 |
| --- | --- | --- | --- |
| 智能体 | 396 / 390 | 153 | 模型按钮把顶栏顶出视口 |
| 视觉评审 | 402 / 390 | 473 | 顶栏溢出 + 页头空白 |
| 运行记录 | 402 / 390 | 445 | 同上 |
| 设置 | 421 / 390 | 124 | 卡片比视口宽 109px |

## 2. 三个根因

### 2.1 页头：`flex-basis: 24rem` 在竖排里变成了高度

`src/styles/page-head.css` 的页头是 `display: flex; flex-wrap: wrap`，标题区 `.vq-head-main`
是 `flex: 1 1 24rem`（24rem = 384px，本意是「放不下就和动作区分两行」）。
≤760px 时页头改成 `flex-direction: column`，但 `flex-wrap: wrap` 没关——
在纵向这个主轴里，`flex-basis: 384px` 变成了**高度**。实测 `.vq-head` 445px（运行记录）、
473px（视觉评审），而里面真正的内容只有 86–128px，剩下的全是空。

修法：

```css
@media (max-width: 760px) {
  .vq-head { flex-direction: column; flex-wrap: nowrap; }  /* 关掉换行 */
  .vq-head-main { flex: none; }                            /* basis 不再参与高度 */
}
```

### 2.2 顶栏：模型按钮不收缩

`.vq-topbar` 是 `justify-content: space-between` 的 flex 行，右组的 `.vq-model-trigger`
按内容宽度（155px）占位，按钮里的文本是 nowrap，缩不下去。390 宽时整条顶栏被顶出视口 12–18px，
**整页跟着横向滚动**；面包屑里的 `strong` 还会折成两行（「运行 / 记录」）。

修法（≤640）：面包屑 `white-space: nowrap` + 省略号；模型按钮限宽 48px、只留图标与箭头
（点开仍是完整列表，弹层宽度改为 `min(288px, 100vw - 24px)`）。

### 2.3 设置页：`1fr` 的自动最小值是内容宽度

设置卡片实测 489px，视口 380px。根因不是卡片写了宽，而是 `@media (max-width: 1180px)` 里的
`.vq-settings-grid { grid-template-columns: 1fr }`——`1fr` 等价于 `minmax(auto, 1fr)`，
自动最小值取内容的 min-content，而卡片里最宽的一行有 405px，轨道就撑到 405px。
全站 20 处 `grid-template-columns: 1fr` 改成 `minmax(0, 1fr)`；账号行在 ≤640 换成两行
（头像 + 邮箱一行，动作一行），邮箱不再被拆成三段。

## 3. 栅格收口（102 处间距 + 23 处字号）

先把规则写成脚本，再按值域机械替换，最后用同一个脚本复扫到 0：

| 原值 | 改成 | 说明 |
| --- | --- | --- |
| 3px | 4px | 最多的一类，含内联声明共 100+ 处 |
| 5px | 4px | 2 处 |
| 6px | 8px | 18 处 |
| 10px | 8px（`gap` 里改 12px） | 21 处 |
| 14px | 16px | 2 处 |
| 20px | 24px | 5 处 |
| 28px | 24px | 2 处 |
| 40px | 48px | 3 处 |
| 56px | 48px | 2 处 |
| 10px / 10.5px 字号 | 11px | 23 处 |

1–2px 保留：只允许出现在 1px 描边内缩与小 chip 的视觉补偿上，这条写进了测试常量
（`HAIRLINE_MAX = 2`），不是「没清干净」。

## 4. 触控目标与截断

- 模板卡「用这条改编」26px → **32px**；智能体卡片上的编辑 / 删除图标按钮 26px → **32px**；
  智能体参数胶囊里的按钮只有 19px 高，改成 `align-self: stretch` 撑满整颗胶囊（30px）再点。
- 视觉评审缩略图标题原来是单行省略，390 下只剩五个字：改成两行 `-webkit-line-clamp: 2`，
  卡片高度用 `min-height: 52px` 对齐。
- 设置页邮箱、工作台「从零搭节点」说明改成允许换行 / 两行截断，不再一个字一个字地断。
