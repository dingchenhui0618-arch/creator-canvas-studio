# 工作台 / 模板库 / 爆款雷达：手机与平板抬一档（r237 / v0.9.221）

结论：这一版先把三页共用的骨架（侧栏导航、顶栏搜索、模型按钮、版本按钮、筛选片、文字链接、上手引导）在 **1080 以下统一抬一档**，再把工作台、模板库、爆款雷达各自的正文与小字抬到 **13px 起**、按钮到 **手机 44px / 平板 40px**。390 / 768 / 1024 三个宽度实测：三页「小于 13px 的文字」从 108 / 111 / 69 处降到 **0**，「不到 40px 的点击区」从 60 / 60 / 60 处降到 **0**，没有横向溢出。模板库顺手把 390 上一张 761px 的大封面卡改成「左 96px 封面 + 右文案」的紧凑行，26 条从 **19,262px 收到 8,308px**（768 从 35,372 收到 5,986）。桌面（1081 起）逐项一个像素没动。

## 三、模板库 390：一张卡 761px → 紧凑行

`≤820` 时模板库原本单列、封面按 9:16 撑满整宽：390 上一张卡 761px、26 条 19,262px，一屏看不到第二条；768 上一张卡 1,374px、26 条 35,372px。现在改成与爆款雷达一致的紧凑行：左 **96px** 封面（仍 9:16）+ 右文案（标题、钩子、互动数、来源、「用这条改编」），`≤360` 封面再收到 **80px** 并把整句说明改成可折行。

| 宽度 | 改前高度 | 改后高度 | 降幅 |
| --- | --- | --- | --- |
| 390 | 19,262px | **8,308px** | −57% |
| 768 | 35,372px | **5,986px** | −83% |

卡片细节见 docs/template-card-r237-390.png（2× 局部截图）：封面 96px、文案列 4 段脚本 / 6 个分镜一行、来源与按钮各占一行。

## 四、320 的一个既有问题

紧凑行刚上时，320 的文案列只剩约 108px，「解析后才能改编与开作品」这一整句（154px）顶出屏幕（右缘 355 > 320）。改法：`≤360` 封面 80px、`.template-meta > span` 允许折行，数字短语（4 段脚本 / 6 个分镜）仍不拆。现在 320 下三页 scrollWidth == clientWidth == 320、无越界元素。

## 五、桌面（1081 起）没动

全部新规则都写在 `@media (max-width: 1080px)` / `560px` / `820px` / `360px` 里。1440 实测逐字段相同：工作台 16 处小字 / 21 个点按区、模板库 24 / 19、爆款雷达 32 / 20，改前改后完全一致；基样式仍是导航 34、搜索 30、筛选片 30/12.5、文字链接 24、雷达作者 11.5、模板按钮 32/11.5、工作台主按钮 36。

## 八、边界（照实说）

- 只按 Chromium（Edge 157）无头实测，**没在真机触屏、Safari、Firefox 上验过**。
- 量了 320 / 390 / 768 / 1024 / 1440；561–767 与 769–1079 没有逐档量（规则按 1080 / 560 两档写，768 同时覆盖 ≤820 的紧凑行）。
- 桌面证据是 1440 与改前逐元素一致，加上「所有新规则都在 max-width: 1080px 以内」；1081–1439 没有单独截图。
- 模板库紧凑行牺牲了封面尺寸（96px）：想看清封面仍要进详情抽屉。
- 骨架规则挂在 `.vq-scope` 与组件类上，后台管理页同样受影响（表里的按钮在平板上也会变 40px）；这一轮没有逐屏复量后台。
- 设置（390 实测 49 处小字）、视觉评审（10 处）、运行记录（8 处）、快捷创作（4 处）这一轮没动，仍在清单里。
