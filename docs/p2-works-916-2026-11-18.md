## 二、作品流：三处产物合成一条

新增 `GET /api/works`（`server/works-feed.mjs` + `server/routes/works.mjs`）：

- 快捷创作：`DATA_DIR/media/tasks/*.json` 里 `status=succeeded` 的图片 / 视频，带缩略图与预览；
- 工作流：`runs.json` 里自己的运行记录（`ownerId` 过滤），带状态；
- 无限画布：`listCanvases()` 的画布卡（名称 / 节点数 / 更新时间），点开进 `#/board/<id>`。

口径：只列成功产出，失败任务留在「最近生成」；翻页用 `at:id` 游标（同毫秒不重不漏），坏游标 400 `WORKS_CURSOR`，坏筛选 400 `WORKS_KIND`，未登录 401。不调上游、不扣积分。

作品页（`src/pages/ProjectsPage.tsx`）默认进「创作成果」：按作品自己的比例排版（9:16 竖版、16:9 横版、1:1、画布 16:9），1440 四列 / 1080 三列 / 768 两列 / 390 两列；点缩略图弹层预览图片或视频，Esc 关闭。原来的「作品项目」列表原样保留，右上角一个按钮切换。
