# 以旧版为底再开一版（v0.9.115，2026-11-14）

## 结论

版本存档已经有了：每一版的画布还在、脚本快照也在。但「v3 改坏了，想回到 v2」之前没有入口——只能打开旧版画布照着改，或者手动把脚本抄回来，改着改着就分不清哪一版才是对的。

这一轮给归档版加了一个动作：**以这一版为底再开一版**。服务端复制那一版的画布与脚本，当前版照常归档，版本号继续往上走。不覆盖、不删除任何历史；v3 仍然是 v3，v4 明确是从 v1 回来的。

## 为什么现在做

v0.9.113 让跨版本运行可以对照，v0.9.114 让每一版改了什么、旧版脚本说了什么都能看见。看得见之后，下一步自然是**回得去**。但回退不能靠改写历史：版本列表、运行记录、评审、交付都按版次认，重写 v3 会让那些记录失去依据。正确做法是**新增一版**，把旧版作为底稿。

这也是上一轮「发现但没做」里明确列出的「旧版恢复/编辑」。这一轮只做恢复中安全的那一半：**以旧版为底开新版**；不提供原地编辑旧版。

## 做了什么

### 1. 存储层：归档当前版，再把新一版的脚本换回旧快照

archiveProjectVersion 新增可选参数 nextScript：

- 先把当前版（画布 + 当前脚本）归档成 vN；
- 作品指向新画布；
- 如果给了 nextScript，再把作品自己的脚本换成这份旧快照。

顺序不能反。如果先换脚本再归档，vN 存下的就会是新脚本，旧版当时说了什么就丢了。

### 2. 路由：POST /api/projects/:id/versions 接受 from

- 不传 from：原来的「复制当前画布，开下一版」。
- 传 from（1 到当前版 - 1 的整数）：
  - 找归档版 vN；
  - 必须存过脚本快照，否则 409 VERSION_SCRIPT_MISSING；
  - 那一版画布必须还在，否则 409 VERSION_FLOW_MISSING；
  - 复制它的节点与连线；画布名写成「作品名 v4 · 以 v1 为底」；
  - 新一版脚本换成 v1 的脚本快照；
  - 返回 basedOn: 1，调用方不用猜。
- from 越界、不是整数、等于当前版：400 VERSION_FROM_INVALID；**不会静默退回「从当前版开」**。

### 3. 作品页：归档版多一个动作，点两下执行

- 每个归档版本的右侧多一枚「以这一版为底」（带旋转图标）。
- 第一下只把按钮换成「再点一次 · 开 v4」，5 秒没有第二下就缩回去；和「清空拍板记录」同一套习惯，不用原生 confirm。
- 第二下才发请求。成功后刷新作品，toast 写「已以 v1 为底开 v4：画布和脚本回到那一版，v3 已归档，记录都还在」。
- 当前版没有这个动作：从当前版开新版就是页头的「开一版新的」。
- 没存脚本快照的归档版按钮禁用，标题说明「没法整版回到当时」。

### 4. 不做什么

- 不删除、不重排、不覆盖任何版本。
- 不回退评审、运行、交付记录：那些仍按各自版次保存；新一版还没跑、没评，就是没跑、没评。
- 复制源画布后不做二次同步：如果源画布里的复刻提示词是手改过的，保留手改；画布与脚本按归档时的样子一起复制。

## 八条坑

1. **先归档、再换脚本**：顺序反了，vN 会存成新脚本，旧版当时说了什么就丢了。store 层一次 persist 里先写归档，再写 nextScript。
2. **from 越界不能静默回落**：不传 from 才是「从当前版开」；传了无效必须 400，否则用户以为回到 v1，实际从 v3 开了一版。
3. **没快照不能假装恢复**：只允许从存过脚本快照的版本回退；没有就 409，并说「只能打开那一版画布手动改」。
4. **画布被删也要拒绝**：归档记录还在但画布没了，不能复制，409 VERSION_FLOW_MISSING。
5. **复制后不要二次 sync**：源画布的手改提示词要保留；画布与脚本按 v1 归档时的样子一起复制，不重新生成。
6. **两下确认要有退路**：5 秒自动缩回，避免误触；不用原生 confirm，视觉与站内一致。
7. **当前行标题仍用作品名**：改名后不能拿旧画布名当标题；来源写在 toast、画布名与 API basedOn 里，不硬塞进版本行。
8. **390 动作组要整组换行**：两个按钮并排会把标题挤成两行；窄屏让动作组落到下一行，断言右缘不超出行。

## 发现但没做

- 不删除、不重排版本；只能在旧版基础上开新版。
- 不回退评审、运行、交付记录：新一版是新的现场，旧记录按旧版保留。
- 当前行不常驻「以 vN 为底」标记：只在 toast、画布名与接口 basedOn 里；版本行标题仍用作品名。
- 不支持跨作品以旧版为底。
- 只允许从有脚本快照的版本回退；更早的无快照版本只能打开画布手动改。
- 不比较非相邻版本；想看 v1 与 v3 的差异仍要自己开两次弹窗或去运行对照。
- 没有真实模板 / 真实运行验证。
