# 上线前缺口与 UX 清单（r214 / v0.9.198，2026-11-18）

用户要求：「你开始自己找距离上线前的地方缺少的东西并修复页面中相应的 bug 内容以及漏洞 还有从 ux 角度的问题 先列出清单来 并一个个开始更改」。

结论：本轮修掉 6 个会伤到真实用户的缺陷；剩下的是**必须用户提供外部条件**（支付商户号、短信资质、备案主体）或**产品取舍未定**（工作流出图/出视频节点），不是改代码就能关掉的。

## 仍然缺（按性质分组）

### A. 只能等用户 / 外部条件

1. **支付**：`billing` 下单 `channel:'internal'` 直接 paid，没有微信/支付宝商户号。
2. **定价与配额**：三档 30/100/300 元 = 300/1000/3000 积分；`usage-prices.json` 全 0；`quota.monthlyLimit` 0（等于不限）。
3. **注册**：`registrationEnabled:false`，`VQ_REGISTRATION` 未开——现在只能管理员建号。
4. **站点公示 6 项**：备案号、主体全称、地址、信用代码、客服邮箱、投诉渠道（`/api/app` complete:false）。
5. **生成式 AI 备案与内容审核**：未办。
6. **短信**：赠送签名移动报备中，日限 200；自申请「VisionQA」签名已驳回。
7. **上游余额**：GeteAPI ¥19.64，低于 ¥20 阈值。
8. **告警外推 / 异地备份**：告警通道未配（历史 13 条，11 条未确认）；`offsite:null`。
9. **生产画布跑 vite dev、整机 2GB 未压测**。

### B. 产品取舍未定

10. **工作流只能跑文本节点**（输入 / 大模型 / 知识库 / 工具 / 条件 / 评审 / 输出），没有出图、出视频节点——这是用户说「工作流鸡肋」的根因。本轮已做的联动：空状态给三条真实入口（爆款雷达 / 模板库 / 作品），运行结果进作品流并带摘要与「打开运行」深链（`#/canvas/<flowId>/run/<runId>`）。**要真正有用，下一步应加图像/视频生成节点**（会新增扣费与异步轮询，需产品确认）。
11. **作品流没有删除 / 搜索 / 按来源筛选到更细**；画布卡没有缩略图。
12. **画布内新建的画布**不会自动出现在 VisionQA 列表（没有归属记录）；需要打开一次完成认领。
13. **对话还没接文件解析 / OCR / 图片理解 / 流式**。

### C. 已知小毛病（未修，记着）

14. `media-gen` 全量并发下偶发一条假失败（单跑 18/18 过），本轮全量首跑踩到、重跑全绿。
15. 390 宽有「这是桌面工作台」横幅，占掉首屏约 80px（有意为之，不是 bug）。
16. 后台大表格仍是容器内横向滚动（设计如此）。
