# 写到一半不许悄悄丢：三个手写编辑面离开前先问一句（r270）

## 为什么做这一轮

产品里有三处「填完自己点保存」的编辑面：作品的脚本、对话预设的表单、工作流的节点（自动保存，但会失败）。改到一半时点侧栏、按浏览器后退、关掉标签页 —— 以前三种情况全都是**一句话都不说，改动直接没了**：

| 编辑面 | 改动存在哪 | 以前的离开路径 |
| --- | --- | --- |
| 作品的脚本（开头钩子 + 最多 12 段） | 只在内存（copy-on-write，保存才落库） | 点侧栏、点「全部作品」、按后退、刷新 —— 全丢，无提示 |
| 对话预设（名称 / 职责 / 系统提示词 / 知识 / 工具） | 只在内存 | 同上 |
| 工作流节点 | 停手 900ms 自动保存 | 保存**失败**时只有保存按钮上一行小字，切页照样丢 |

这三处都不是「保存坏了」，而是「离开时不问」。用户丢掉的是自己刚写的东西，事后连发生了什么都说不清。

## 做法：登记 → 路由拦 → 弹窗问

分三层，只有一处真源：

1. **页面登记**（src/domain/unsaved-guard.ts）：setUnsaved({ owner, message }) / clearUnsaved(owner) / unsavedNote()。owner 只让页面清掉自己那一条 —— 后挂上的页面不会把前一页的登记抹掉。
2. **路由挂起**（src/router.ts）：navigate() 先比 routeKey，**真有没保存的改动、而且地址真的换了**才挂起，不写地址；浏览器的前进 / 后退在 handleHashChange 里先把地址改回去，再走同一句话。
3. **问一句**（src/App.tsx）：.vq-leave-modal（role="alertdialog"，danger 在左、primary 在右并拿焦点）。选「丢下改动，离开」才真正落地址；选「留在这页」什么也不写。关标签页 / 刷新这一层只能用 beforeunload 交给浏览器自己弹。

判定本身是纯函数（shouldAskBeforeLeave），5 条单测钉住：没登记不拦、换了地址才拦、同一条地址自己回写不拦、只清自己那一条、文案原样取回。

## 三个编辑面的口径

| 页面 | 什么时候登记 | 弹窗里那句话 |
| --- | --- | --- |
| 作品 · 脚本 | 开编辑那一刻存一份基线，逐字比出「改过」，且只在改过时登记 | 这条作品的脚本改了还没保存，现在离开就丢了。想留着就选「留在这页」，写完点「保存脚本」。 |
| 对话预设 | 表单载入时存基线，逐字比；改过才登记 | 这个对话预设改了还没保存，现在离开就丢了。想留着就选「留在这页」，写完点「保存修改」。 |
| 工作流 | 只有**保存失败**（saveState === error）才登记 | 这个工作流这次没保存成功（原因），现在离开改动就丢了。留在这页按 Ctrl+S 再存一次试试。 |

配套的小改动：作品脚本的「取消」按钮改过才问一句（打开看一眼就关不该拦）；三处保存成功后都**先撤登记再跳转** —— 不撤的话，刚存好的那一页会被自己刚才的改动拦下来。

## 取舍

- **不用 window.confirm**：原生框只说「确定离开吗」，说不出丢了什么，而且和这套界面不是一个东西。代价是多一个弹窗组件。
- **同一条地址自己回写不拦**：画布保存后补 runId、页内补查询串都走 navigate，拦了会把人卡在自己页上。
- **自动保存中那 900 毫秒不拦**：它自己会存下来，为这个窗口弹一次只会打岔。
- **保存成功先撤登记**：否则「存完回列表」会被自己拦住。
- **后退的先还地址再问**：按后退时先把地址改回原处，再弹同一句话。代价是历史里会多一条同地址记录，连按后退要多按几次。

## 验证（本机临时实例 + 无头 Chrome，真点）

临时实例：临时 DATA_DIR + 一个走查账号 + 一条空作品（createProject，没有模板、没有工作流），上游地址指向 127.0.0.1:9 —— **0 次真实上游调用、0 费用**。

| 断言 | 结果 |
| --- | --- |
| 改了名称后点侧栏「工作台」 | 地址仍是 #/agents/new，弹窗出现，标题「这一段还没存下来」，按钮「丢下改动，离开 / 留在这页」 |
| 选「留在这页」 | 弹窗消失、人还在编辑页、刚敲进去的字还在 |
| 再点一次，选「丢下改动，离开」 | 地址变成 #/overview |
| 没有改动时点「作品」 | 一次就过去（#/projects），不弹窗 —— 不误伤 |
| 作品中「写一条脚本」→ 改第一段 → 点侧栏 | 地址仍是 #/projects/prj_…，弹窗出现，文案是脚本文案，改的字还在 |
| 按浏览器后退 | 地址弹回 #/agents/new，弹窗出现；选「留在这页」后内容仍在 |
| 390 宽 | 弹窗 342×278、按钮竖排、scrollWidth == innerWidth == 390 |
| 控制台 | 0 条异常 |

## 边界

- 只接住这三处**手写编辑面**。作品页的「回执 / 交付收口」输入框、后台各表单没接这一套。
- 关标签页 / 刷新那一层只能用浏览器自己的文案（beforeunload 不允许自定义），我们只能决定「拦不拦」。
- 后退被拦下后历史里会多一条同地址记录，连按后退要多按几次。
- 只在浏览器里验了「对话预设」与「作品脚本」两条路；工作流那条靠 saveState 变成 error 触发，临时实例里不好造保存失败，**未真点过**。
- 拦截只对「这一次改动的页面」有效；跨页面的草稿（比如在对话里让 AI 起草的信）仍按原样走，不在这一套里。
