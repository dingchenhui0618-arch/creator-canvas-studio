# 运营位两处手感：整卡可点、关掉能撤（r326 / v0.9.298）

2026-11-26。用户这一轮的原话还是那三句：「我主要是在一些小的细枝末节上，比如某些小的动效，某些广告模块，
某些用户 UX 体验上的感觉」。所以这一轮只动运营位（用户说的「广告模块」）这一块，两件事：

1. **整卡可点**：卡片悬停会抬起（`.vq-lift`），却只有右下那颗按钮能点——「提起来了却按不动」。
2. **关掉能撤**：以前点错 ✕ 就再也回不来了（只写本地存储，界面上没有任何入口）。

---

## 一、整卡可点，以及那个只在手里才出现的坑

### 做法
不给 `<article>` 挂 `onClick`、也不把按钮套进按钮（嵌套交互元素），而是用 CTA 按钮的 `::after` 铺一层
透明热区盖住整张卡（stretched link）：

```css
.vq-promo-cta { flex: none; }            /* 注意：不能设 position —— 见下 */
.vq-promo-cta::after { content: ''; position: absolute; inset: 0; }
.vq-promo-close { position: relative; z-index: 1; }   /* ✕ 必须压在热区之上 */
```

参照物是 `.vq-promo`（它本来就是 `position: relative`），所以热区正好是整张卡片。
键盘这条路不变：Tab 一格落在按钮上、回车触发，读屏读到的也是按钮自己的名字。

### 坑：全站那个 1px 的按下反馈，会把这层热区在按下的瞬间吃掉
第一版按上面的写法做完，DOM 里量什么都是对的：`::after` 是 `absolute` + `inset: 0`、
`getComputedStyle(::after).width` 是 1138px（整卡宽）、`document.elementFromPoint` 在正文正中返回的
**就是那颗按钮**。可是一真点，什么都发生了就是没跳页。

给页面挂上一个 click 捕获监听（记录 `mousedown`/`mouseup`/`click` 各自的 target）之后真相出来：

```
mousedown → BUTTON.vq-button.vq-promo-cta     热区还在
mouseup   → H3.vq-promo-title                 热区没了
click     → ARTICLE.vq-promo.vq-lift          「按下与抬起的共同祖先」——那张卡片
```

根因在 `tokens.css` 给全站按钮的按下反馈：`:where(.vq-button, …):not(:disabled):active { transform: translateY(1px) }`。
**带 `transform` 的元素会成为绝对定位后代的包含块**——按下的一瞬间，`::after` 的参照从「整张卡片」
变成「按钮自己」，热区当场缩成 115×32，鼠标抬起就落回下面的标题上了。
（同一段里还做了一个对照夹具：一个 300×100 的定位容器里放一个 `::after` 铺满的链接，
点容器下半部分 → `mousedown/mouseup/click` 全落在 `A` 上、地址真的跳了。所以不是「伪元素接不住点击」，
是我们这张卡片自己把参照换掉了。）

修法是把这一颗按钮的按下反馈换成不产生包含块的那种：

```css
.vq-promo-cta.vq-promo-cta:active { transform: none; background: var(--line-faint); }
```

选择器写两遍类是为了压过 `tokens.css` 那条 0-2-0 的规则（样式表按需加载，顺序不保证；
这个文件里 `.vq-lift.vq-lift`、`.vq-promo.is-leaving.is-leaving` 都是同一个理由）。

**这一条值得单记**：编译、类型、样式、单测全都看不出问题，DOM 检查也看不出问题，
只有真的按下鼠标才会出现。所以取证脚本里专门加了一步「按住不放」：
按下但不松开，热区必须还在、CTA 的计算 `transform` 必须是 `none`。

## 二、关掉能撤

```
已关掉「把几个智能体放进同一个房间」                                            [ 撤销 ]
```

* 关掉之后，那条卡片塌下去的位置上出现这条**虚线**条子（实线卡片会被当成「还没关掉」）。
* 文案：只关一条写标题（用户要确认的正是「刚才手滑的是不是这条」），连关几条写条数
  （`promoUndoLabel`，纯函数）。
* **8 秒窗口**（`PROMO_UNDO_MS`）：槽里还有别的运营位时到点自己退场；退场走与卡片同一套塌陷配方
  （先钉住高度、下一帧收到 0，内边距与描边一起收——r322 量出来的那两处）。
* **槽被关空了就不退**：那时候它是唯一的入口（关掉只写本地存储，刷新不会自己回来）。
  这条分支只在这一次浏览里有效——刷新之后关掉的记录照样生效、条子不再出现
  （一个跨会话挂着的「撤销」更像没关干净）。
* **光标停在条上、或键盘正停在「撤销」上时不抽走**：手伸过去的那一下正好到点最气人。
* 「撤销」把这几条从「关掉过」名单里拿掉并写回本地（`withoutDismissed` + `restorePromos`），
  卡片按 `.vq-stagger` 的进场重新出现，同一屏其它位置的同一条也一起回来。
* 间距也一并处理了：条子的上边距挂在它自己身上，`.vq-promo:has(+ .vq-promo-undo)` 把上面那张卡片的
  下边距让出来——不然条子退场被移除的瞬间，下面会跳 8px（r322 修过一类同样的问题）。

## 四、门禁（`test/promo-undo.test.mjs`）
这一轮的两件事都能被一次「看起来改完了」的编辑悄悄废掉（最像 r322 那个坑的：
`if (!list.length) return null` —— 槽被关空的时候，正好把唯一能撤销的入口一起藏了）。
所以新增一组**真源码扫描 + 反证**：

* 热区：`::after` 必须 `absolute` + `inset: 0`；`.vq-promo-cta` 自己不许定位（否则参照变成按钮）；
  ✕ 必须 `z-index: 1`；**CTA 在 `active` 时不许有 `transform`**
* 撤销：整块不渲染的条件必须把撤销条算进去；撤销按钮必须真的调 `restorePromos`；
  条子退场期间按钮 disabled；条子退场必须走塌陷那条规则；间距必须挂在条子身上
* 反证：把上面每一条改坏（删掉 `transform: none`、`z-index` 改 0、`inset` 改 4px、
  条件改回 `if (!list.length)`、去掉 `restorePromos`、去掉写回本地），检查必须变成「有问题」

## 五、边界
* 热区让卡片上的文字**点选不了**（热区在上面）。这张卡片本来就只有一句话，判断是不值当为它留选择区；
  真需要复制的话，改回「只有按钮可点」即可（删掉 `.vq-promo-cta::after` 那一条）。
* CTA 仍然是 `<button>`，所以**中键/⌘+点击开新标签页这一条没做**（那要把按钮换成 `<a href>`，
  会牵动 `.vq-button` 的下划线重置）；普通点击、回车、空格都正常。
* 撤销窗口只有 **8 秒**，退场之后关掉的那条就真的不再出现（清站点数据才会回来）。
  条子只在**这一次浏览**里有效：刷新/切页之后关掉的记录照样生效，但不再给撤销入口。
* 关掉只记在这台机器的浏览器里（换设备、清缓存会重新出现），这是 r320 起就有的口径，没有改。
* 这一轮**没有**碰运营位的取数、后台编辑卡、缓存与权重排序。
