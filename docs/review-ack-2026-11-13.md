# 看过不等于改过：「已看过」给评审待办一个出口（v0.9.20）

结论先行：上一轮给工作台加的「评审等你看的」只有入口、没有出口——一条结论是「需人工确认」的作品，
不改就永远躺在待办里，催到你不想再看这个区块。这一轮补上出口：**每行一个「已看过」，把它从待办里拿掉，
随时能撤销；评审结论、状态胶囊、交付稿一个字都不动。**

## 一、为什么是「已看过」，不是「忽略」也不是「通过」

| 说法 | 它暗示什么 | 为什么不用 |
| --- | --- | --- |
| 忽略 | 这条不用管了 | 意见还在，随时可能回来改；「忽略」把真实状态藏起来了 |
| 已通过 | 人确认可以发 | 那是人工复核，要改结论、胶囊、交付稿与评审对照纸的口径，另开一轮 |
| **已看过** | 人看过这一版，先不改 | 只回答「待办清不清」，不碰任何结论；可以撤销，可以回退 |

所以这一轮只做一件事：**待办有出口，且出口不撒谎**。页面上写的是「已看过 N 条，这一版先没改」，
不是「已处理」「已通过」。

## 二、口径（都能在测试里读到）

「已看过」记在**哪一版 + 哪一次评审**上（作品 id + 版次 + 评审时间），不是记在作品上：

| 情形 | 结果 | 为什么 |
| --- | --- | --- |
| 标记已看过 | 从待办挪到下面一行「已看过」，可撤销 | 待办清掉，记录还在 |
| 同一版又评出新结论 | 时间对不上 → **自动回到待办** | 新的评审就是新的意见，看过上一次不等于看过这一次 |
| 作品开了新版 | 版次对不上 → 不回待办（新版还没评过，没意见可看） | 待办只认当前这一版，与胶囊同一套口径 |
| 结论是通过，或作品已交付 | 既不在待办，也不在「已看过」 | 不需要动手了，催也没意义 |
| 撤销 | 回待办 | 出口要能掉头 |
| 作品被删 | 那条「已看过」一起删掉 | 便利贴跟着作品走，不留对不上的记录 |
| 注销账号 | 一起清掉 | 与评审、作品同一套清理 |

不调模型、不扣积分、不改评审记录——它只是待办上的一个便利贴，一个账号最多 200 条。

## 三、界面

- **工作台队列每行两个动作**：整行进作品（主体）+ 行尾「已看过」（11px、灰、悬停提亮）。
- **行本身不再是按钮**：按钮里不能套按钮，整行可点改成「主体那颗按钮铺满左侧」；aria-label 写清打开哪条作品第几版。
- **已看过的写在队列下面一行**：「已看过 N 条，这一版先没改 · 最近：作品（第 N 版 · 时间 看过）」+「撤销」。
- **都看过了**：空状态换成「等你看的都看过了」，并写明「看过不等于改过：作品状态还是评审 · 需人工确认 / 不通过」。
- **主卡**：队列空了就退回最近作品，CTA 从「按意见改这一版」变「继续这个作品」；状态标签仍是评审结论，不改口。

## 四、顺手修三处

1. **按钮字号被打回 16px**：全局 .vq-scope button { font: inherit } 比 .vq-button 更具体，
   行尾这个 11px 小动作只能写在更具体的选择器上，并在 CSS 里注明原因（不顺手改全局，影响面太大）。
2. **窄屏时间被劈成两行**：11/13 与 00:40 拆到两行；时间包一层 nowrap，要么整块留在上行末尾，要么整块落到下一行。
3. **窄屏箭头让位给动作**：整行本来就能点，箭头在 390 宽只是装饰；去掉它（和图标）把宽度还给作品名与「已看过」，两档都不横向滚动。

## 六、本地演示数据验的部分（不是生产）

生产只有 1 条作品、2 次评审，所以这些只能在本机演示数据（3 条作品 / 26 次评审，.tmp-qa/r86data）上看：

- 两条待办同时存在（不通过 + 需人工确认），标掉一条 → 剩一条 + 「已看过 1 条」；标掉两条 → 「等你看的都看过了」；撤销两次 → 回到两条。
- 主卡跟着队列走：标掉第一条后主卡换成第二条；全标掉后变「继续这个作品」。
- 390 宽：胶囊在作品名上面一行，时间整块不劈开，「已看过」51×32，无横向滚动。

## 七、边界（这一轮刻意不做）

- **「已看过」不等于「通过」**：不改结论、不写人工复核、不让作品直接进「下一步 · 交付」。
  人工复核（人拍板通过 / 不通过）要改结论与四张纸的口径，下一轮再说。
- 没有时间范围、关键字搜索：待办上限 20 条、工作台只看前 3 条，暂时不需要。
- 只有工作台知道「已看过」：作品页、作品列表、评审历史都不显示这条状态——它们是结论侧，不是待办侧。
- 没有通知 / 角标：评审跑到一半关掉页面，回来还是靠工作台这块。
- 已看过的记录留在数据目录（review-acks.json），删作品 / 注销账号会一起清。
