# 作品列表卡片上直接看得到分享状态（v0.9.13）

上线：2026-11-12，生产 visionqa.wavisionai.cn，版本 0.9.13。

## 为什么做这个

v0.9.11 能在作品页回看每一轮打开情况，v0.9.12 把跨作品的汇总放到工作台——
但那两处都要求你先知道「去看哪一条」。真正每天翻的是作品列表：
扫一眼就知道哪条还在分享、有人打开过没有、已经停掉的那条被人看过几次。
这一轮把这条摘要挂到列表接口的每一项上，卡片自己就能说清楚，不用点进去、也不用先回工作台。

## 长什么样

作品卡片顶部那排状态胶囊多一枚：

- 正在分享：绿点 + 「分享中」（与「评审 · 通过」用同一套绿：`--pass` / `--pass-soft`）；
- 已经停用：一圈灰描边 +「已停用」，不抢状态胶囊的视觉；
- 从没分享过：不显示这枚胶囊，卡片不多一个空壳。

下面那排指标从四格变五格：脚本 / 分镜 / 评审 / 运行 / **打开**。
打开次数写在第五格（`4 次`，没打开过是 `—`），鼠标停在胶囊上能看到详情：
「共 3 轮链接，打开 4 次，最近一次 11-12 16:08（电脑浏览器）」。

## 三个实现决定

1. **摘要挂在列表接口里，不让页面再调一次 `/api/shares` 拼**。
   工作台的汇总是按「最近有人打开」排序、只回 6 行的——按项目去这张表里找，作者一多就会被截掉。
   列表接口本来就按作品返回，顺手带上每一条自己的那一条摘要，一次请求、不用等第二个接口。
2. **只挂一条摘要，不带凭证**：`live / rounds / opens / lastAt / lastClient`。
   列表是「谁能看作品」的同一套归属规则，但 token 与记录键没必要跟到列表里；
   每一轮的停用时间与明细仍然只在作品页的分享面板（v0.9.11）。
3. **胶囊管状态、第五格管次数**。两件事塞进一个胶囊的话，文案会随次数变长变短，
   390 宽下会把右上角的时间挤走；分开之后胶囊是固定宽度（62px / 52px），指标行一格格对齐。

合并算法与工作台汇总共用 `server/share-summary.mjs`：同一个 `shareRows()` 出结果，
工作台要整行（含 visits 对象），卡片要 `shareBrief()` 那一小条。两处不会各算一遍次数。

## 量到的

生产真实作品（「毛衣折叠收纳法」，四轮链接：2 + 1 + 1 + 0 次打开）：

| 读的地方 | 读数 |
| --- | --- |
| `/api/projects` 每项的 `share` | `{live: false, rounds: 4, opens: 4, lastAt: '…16:08:39Z', lastClient: 'desktop'}` |
| 列表响应体 | 没有 token、没有 `key`、没有 `shareHistory`、没有 `visits` |
| 分享中（1440） | 卡片 562×238px，胶囊 62×22px，指标五格各 96px，无溢出 |
| 已停用（1440） | 同尺寸，胶囊 52×22px，第五格仍是「4 次」 |
| 分享中 / 已停用（390） | 卡片 290px 宽，指标五格各 42px，`scrollWidth == clientWidth` |

## 边界

- **次数不是人数**：同 v0.9.10，没有账号就没有身份，卡片上只写次数。
- **只算这条作品自己的各轮**：历史最多 8 轮，更早的轮次会被挤掉，累计随之少掉那几轮。
- **打开记录上限 200 条**：被挤出的旧链接不计入累计，这是记录本身的边界。
- **停用不等于清零**：胶囊变灰，次数留着——那是发生过的事。
- **卡片只是状态**：不提供复制链接、开关分享，那些操作仍在作品页的分享面板里。
- **摘要不是分析**：没有来源、没有停留时长、没有逐次时间线，和上一轮同一口径。

## 复验命令

```powershell
# 接口：登录后拿任意一条作品的 share 摘要（不带 token / 记录键）
curl.exe -s -b cookies.txt https://visionqa.wavisionai.cn/api/projects
# 测试：卡片摘要的四个场景（在分享 / 停用后 / 第二轮 / 删除作品）
node --test test/projects-share-badge.test.mjs
```

## 改到的文件

- `server/share-summary.mjs`（新）：`mergeVisits`、`shareRows`、`shareBrief`——工作台汇总与卡片摘要共用一套合并。
- `server/routes/shares.mjs`：改用共用模块，路由本身只剩「取列表、切片、求和」。
- `server/routes/projects.mjs`：列表每一项挂 `share` 摘要（没分享过是 `null`）。
- `src/domain/project.ts`：`ProjectShareBrief`，`ProjectSummary.share`。
- `src/pages/ProjectsPage.tsx`：卡片加「分享中 / 已停用」胶囊、指标行第五格「打开」，悬停文案走 `shareHint`。
- `src/styles/projects.css`：`.vq-project-share`（含 `is-live` 与 6px 圆点）、指标行改五格。
- `test/projects-share-badge.test.mjs`（新，4 条）：在分享 / 停用后次数仍在 / 第二轮累计 / 删除作品。
