# 快捷创作「一屏收高」与输入卡密度（r259 / v0.9.242）

日期：2026-11-19。范围：只动快捷创作（`src/pages/AgentsPage.tsx`、`src/styles/agents.css`、
`test/quick-composer-unified.test.mjs`）。服务端、计费、模型路由一行没动，
**本轮 0 次真实出图 / 出视频调用**。

## 一、问题（用户视角）

1. **图片 / 视频页签不是「一屏」**：这块原来是「内容多高就多高」——出一次图以后，结果卡、
   输入卡、下面那一整块「已自建对话预设」一起把页面撑成两屏。生成时视线要来回滚，
   想把提示词改一个字得先滚回去找输入框。
2. **「已自建对话预设」长在图片 / 视频页签下面**：它跟出图没有关系，却是这一页最长的一段
   （1440 上 322px、390 上 334px）。
3. **对话预设的输入卡比「平台对话」胖一圈**：平台对话那张是 8px 内边距 + `--radius-md`（14px），
   对话预设这张是 16px 内边距 + `--radius-xl`（24px）。同一页切个页签像换了产品。
4. **参考素材区在「当前方式不收」时仍占一整块**：两枚灰按钮 + 两行说明，
   1024×768 上光这一块就把「这次的结果」挤成一条缝。
5. （上线后在生产截图上才看出来的）**「最近生成」的行会被内容撑宽**：失败任务的原话是
   nowrap，它的 min-width 等于整句上游原文，把整行顶出左栏——生产上「用作参考 / 下载」被裁掉，
   列表底下多出一条横向滚动条；同时提示词被按钮挤成一行的「生成…」，一条都认不出是哪张图。

## 二、改法

### 1. 图片 / 视频与「平台对话」共用同一个骨架

新增页面标记 `agx-page--media`（桌面 ≥901px 生效）：

| 区块 | 改前 | 改后 |
| --- | --- | --- |
| 整页 | 内容撑高，页面滚 | `height:100%`，一屏；只有中间那列自己滚 |
| 左栏「最近生成」 | 最高 560，任务多了整页变长 | 拉满一屏高；头一行固定，清单在 `ul` 里滚 |
| 右栏「这次的结果」 | 跟着内容长，把输入卡顶下去 | 按内容高、多了在里面滚（至少 88px） |
| 输入卡 | 结果卡下面 | `margin-top:auto` 钉在这一列底部，永远在屏幕里 |
| 「已自建对话预设」 | 图片 / 视频下也显示 | 这一页不显示（它属于「对话预设」页签） |

矮一点的桌面屏（高度 ≤820px，如 1024×768）：空的「一句话出一张图」占位卡直接让位——
输入卡才是一屏里最该在的东西。

### 2. 输入卡密度收到一处

`.agx-composer` 的默认值改成与 `.qc-composer` 一致：`padding: 8px`、
`border-radius: var(--radius-md)`；文本框 `min-height 92 → 72`、`padding 8px`、`max-height 240`；
底部参数行 `padding-top 12 → 8`。图片 / 视频那张卡不再单独覆盖密度（原来那段覆盖已删）。

### 3. 参考素材区：不收就收成一行

当前方式 `maxRefs === 0` 且托架里没有素材时，整块参考区换成一行
「「文生图」不收参考素材：切到「参考图」才会带上」。托架里有东西时照旧显示网格与移除按钮。

### 4. 「最近生成」的行：标题整行、动作另起一行

- `.agx-media-recent-open` 从 `flex: 1` 改成 `flex: 1 0 100%`：提示词与元信息占满整行，
  「用作参考 / 下载」落到下一行，不再把提示词挤成三个字。
- 提示词 `white-space: nowrap` 改成两行 `-webkit-line-clamp: 2`。
- 失败原话 `.agx-media-recent-why` 加 `min-width: 0`，清单轨道写成
  `grid-template-columns: minmax(0, 1fr)`、行加 `min-width: 0`、清单 `overflow-x: hidden`：
  上游原话再长也只能出省略号，不能把整行撑宽。
