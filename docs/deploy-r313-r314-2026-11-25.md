## 怎么发的

走仓库既有链路（`ops/deploy.sh`，不重跑 `install.sh`）：

1. 本地 `npm run build`（`tsc -b` + vite build）；
2. 打包 `tar -czf vq-r31x.tgz dist server scripts package.json deploy`
   （v0.9.286 = 12,661,791 B / 681 项；v0.9.287 = 13,238,719 B / 688 项，多出来的就是 5 张示例图）；
3. `scp` 到 `/tmp/vqdeploy-r31x.tgz`，解开到 `/tmp/vqstage-r31x`；
4. `bash /tmp/vqstage-r31x/scripts/deploy.sh <包> <标签>` —— 先给当前版本打快照，再替换
   `dist / server / scripts / package.json`（`data` 不动），重启两个服务并自检健康。
