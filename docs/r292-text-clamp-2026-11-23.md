# r292：三处「字被挤没了」（v0.9.274 -> 合并进 0.9.275）

## 怎么找到的

在生产站用真实数据只读走查（临时管理员会话，用完即撤销）：7 个用户页 × 1440 / 390 两档，
量「横向溢出 / 文字被裁 / 可点区域过小 / 接口 4xx-5xx / 控制台异常」。

结论：**0 个接口报错、0 条控制台异常、0 处横向溢出**，但量出三处文字被挤成省略号——
这是 0.9.272 那次「字阶整体 +1px」的连带问题：字变大一点，原本刚好放下的列宽就不够了。

| 位置 | 改前实测 | 改后实测 |
| --- | --- | --- |
| 评审页「最近评审」标题 | 列宽 43px（1440）/ 33px（390），「毛衣折叠收纳法 · v2」只剩「毛衣…」 | 标题独占一行 248px，完整显示；结论胶囊与时间退到第二行 |
| 同一行归属 | 「作品 · 毛衣折叠收纳…」版本被切掉 | 两行放得下「作品 · 毛衣折叠收纳法 · 第 2 版」 |
| 运行记录归属 | 一行截断，切在括号里（第 1 版（归…） | 最多两行，1440/390 都完整（scrollHeight == clientHeight） |
| 作品流竖卡标题 | 一行截断，长标题只剩前半句 | 两行；桌面字号仍 15px，没顺手放大 |
| 作品流「时间 · 模型名」 | 「Seedance 2.0 · 极速」截成「Seedance 2…」 | 允许折行，读全 |

## 改了什么

只动三个样式文件，没有新接口、没碰服务端、没碰计费：

- `src/styles/review.css`：左侧那张卡片原来是三列网格（胶囊 + 标题 + 时间 挤一行），改成
  `grid-template-areas: 'title title' 'verdict time' 'where where'`，标题第一行独占，
  标题与归属各最多两行。弹层（`.review-history-modal`）列宽够，不受这条规则影响。
- `src/styles/runs.css`：`.runs-row-where` 从「一行 nowrap + 省略号」改成两行 clamp。
- `src/styles/works.css`：`.works-title` 两行 clamp、`.works-time` 允许折行。
- 新增 `test/text-readability.test.mjs`（3 条）：把上面三条规则钉住，并明确「桌面标题不许顺手放大到 16px」
  「弹层布局不许被列表规则带走」。
