# 快捷创作页头收成一条工具条（r307 / v0.9.280）

日期：2026-11-24。用户要求：「顶部无需具体描述这里 腾空页面空间」，参照运行类工作台（如 runow / runninghub 的 agent 页）把页面顶部压薄。

## 改了什么

改之前，从页面顶到对话卡之间要过四段：

| 段 | 高度 |
| --- | --- |
| 全站页头 PageHead（kicker + 32px 标题 + 那句说明 + 20px 下边距） | 约 122px |
| 创作方式一行（对话 / 图片 / 视频） | 约 48px |
| 对话方式一行（平台对话 / 对话预设） | 约 45px |
| 舞台上留白 | 16px |
| **合计** | **约 231px** |

现在只有一条工具条：左边是创作方式，紧跟一道发丝线之后是对话方式（只在「对话」页签出现），右边是工作流去路与「历史 / 新建对话预设」。

- 标题与那句「写文案、出图片、出视频都在这一页……」撤掉。面包屑上已经写着「快捷创作」，同屏再写一遍是重复；页面级标题改为读屏可读的 `h1.agx-sr-only`，搜索与读屏仍拿得到。
- 「对话预设」旁边原来挂着「带输出类型与草稿出口：存模板 / 送工作流 / 写进作品」整句，现在收进这枚页签的 `title`。
- 「历史 / 新建对话预设」只在「对话」页签出现：它们是对话预设的账，图片、视频页签上不该抢一个主按钮（原来两边都有）。
- 工具条本体：`border-bottom: 1px solid var(--line)` 收底，上下 12px（4/8 栅格）。

## 实测（本机临时实例，独立数据目录，不打上游）

1440×900：

| 位置 | 改前（按 CSS 计） | 改后（实测） |
| --- | --- | --- |
| 页头 + 页签 | 231px | 工具条 52px |
| 对话卡顶边 | 约 323px | **160px** |
| 对话区高度 | 约 553px | **716px** |

省下约 163px，全部给对话区：1440×900 上对话卡从 160 一直到 876，输入卡还钉在屏幕里。

390×844：

| 状态 | 工具条高度 |
| --- | --- |
| 平台对话 | 119px（两行：创作方式 / 对话方式 + 工作流） |
| 对话预设 | 171px（三行：多一行「历史 / 新建」） |
| 图片 / 视频 | 107px（两行：创作方式 / 工作流） |

390 上原来这块是「三行页头 + 两行页签」约 250px；现在两行 119px。320 宽没有横向溢出（`scrollWidth == innerWidth == 320`），预设态在 320 会多折一行，按钮左对齐成一叠。

## 顺手修掉的一处横向溢出

320 宽、对话预设态：`历史 + 新建对话预设` 两个按钮合计 242px，比这一列（220px）宽，`.agx-head-actions` 又没有 `flex-wrap`，整页被撑出 6px 横向滚动（`scrollWidth 326 > 320`）。加上 `min-width: 0; flex-wrap: wrap` 后 326 → 320，按钮改为换行而不是撑破。
