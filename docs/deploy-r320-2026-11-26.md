## 这一轮踩到的两个坑

- **接口字段名读错了**：`GET /api/promos` 回的是 `{ ok, promos }`，生产脚本第一版读 `api.items`，
  于是「生产接口没下发运营位」——页面其实一直是好的（前端读的就是 `promos`）。**分清「产品错了」和「断言错了」。**
- **后台徽标的类名不是 `vq-badge`**：`Badge` 走的是 `components/ui.tsx` 的 `Pill`，落到 DOM 上是 `.vq-pill`；
  按想当然的类名取，取到空串，误报「后台没有标出来源」。断言要么按文本找，要么先读组件再写选择器。

## 边界

- 本轮 **0 次真实上游调用、0 积分**：只启临时实例与生产快照，不调任何模型。
- 生产运营位**还是默认内容**（`source=default`）：**没有在生产后台真保存过**，所以「管理员改完用户刷新就变」
  这条只有本地真渲染 + 单测证据，生产上只证明了「卡在、读得到、预览对」。
- `recharge` 位置已进枚举与后台下拉，但**界面上还没挂槽**（充值页还没渲染 `PromoSlot`）。
- 生产 `/opt/visionqa` 仍不是部署版本的 git 检出，回滚只走 `ops/rollback.sh`。
