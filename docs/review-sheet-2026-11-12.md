# 评审对照页：把评审说的问题框回画面上（v0.9.8）

结论：交付包里多了一张 **评审对照页.html**。评审当时说过「红色标题压住折叠起点」，
这张纸把那条判断的框画在原片帧上，框上的编号对到右边的问题列表——左边 1 号框，就是右边第 1 条。
线上也能直接打开：`/print/projects/<id>/review?tz=480`。

## 为什么做

评审结论里每条问题本来就带一个证据框（相对画面的 x/y/w/h），作品页的评审画布上也一直
会高亮。但这些框只活在页面里：交付包发给剪辑、拍摄、甲方之后，他们拿到的是
「右下角按钮距容器底边 0px」这样一句文字，对着哪一帧、哪一块，全靠猜。

所以这张纸只做一件事：**让每条判断在纸上也能被指出来**。它和交付稿是同一份数据、同一次导出，
不是另写一份结论。

## 纸上有什么

- 抬头事实表：作品编号、版本、评审版次、导出时间。
- 每个被评过的版本一块：左边是评审当时的画面，框用编号标出；右边是评审对象、时间、模型、
  判断层（依据 / 可执行 / 发布风险）、一句话结论，然后是同一批编号的问题、修正建议、
  这次没判断的。
- 纸脚写明两件事：框是评审当时给出的位置、不是人工复核；以及画面在包里是哪一张
  （本例就是 `frames/shot-01.jpg`）。
- 底栏：`5 条问题（5 条带框） / 1 版`——数得出来，不用数纸。

## 三个实现决定

1. **每一版只印最近一次评审。** 同一版重评三次的中间结论留在作品页；纸只回答「现在这一版
   被指出什么」。版本 0 的记录（版本划分之前）按页面同一套规则折进 v1，纸上不会出现 v0。
   超过 3 版时只印最近的 3 版，抬头写 `3 / 7 版`，读者知道纸不是全部。
2. **画面只认我们自己存下的帧图。** 评审评的是 `frames/<模板 id>/<文件名>` 就画；评的是外部图片，
   纸上不替它下载，写「这次评审的画面不在我们的帧图里」。导出时联网取图等于开了个出口，
   也说不清取回来的是哪一张。交付包里如果这张帧图本来就在（本例 `frames/shot-01.jpg`），
   直接复用同一个文件，不再复制第二份；不是同一条模板的帧，才复制到 `评审/对照-01.jpg`。
3. **框是相对画面的比例，不是重画的像素。** 坐标 0–1 压到边上会裁进画面；整块出画面的框
   直接不画——纸上不能出现一条伸出纸外的线。第二条问题（框贴到 x=1.2）在实测数据里就是这种，
   所以纸上是 5 条问题、4 个框，底栏照实数。

## 交付稿（.md）也跟着补了

单独下 `交付稿.md` 的人没有那张纸，所以每条问题后面补了框的百分比：

```
1. **重要 · 构图与裁切**：红色标题「毛衣折叠」横跨 x0.14–0.58，压住毛衣上缘折叠起点，也压在手部下方。（依据强度 85% · 框 x 13–60% · y 45–57%）
```

问题列表末尾再加一句：`证据框：5 条问题在画面上框了位置（编号同上）。画面与框的对照图见交付包里的
「评审对照页.html」；只拿到这份稿时，按括号里的百分比对着原图找。`
编号与纸上完全一致（都是同一条 observation 的序号），不会出现「纸上 3 号、稿里第 4 条」。

| 框 | 5 条问题 / 4 个框，位置与画面逐一对齐 | 同左 |

- 作品页「交付」菜单现在有 5 项：交付稿 / 打印稿 / 现场页 / **评审对照** / 交付包；

## 边界

- **不是人工复核**：框来自模型评审，纸脚每次都写清；判断层（依据 / 可执行 / 风险）只是依据，
  不改结论。
- **评的是哪张就是哪张**：评审评的是模板首帧，纸就印首帧；不拿分镜里别的帧顶。
- **帧图被清理过**（模板回收站 / 过期清理）时，纸上只印问题与编号，写「不在这份产物里」。
- **一条问题超过 8 条**（模型上限是 5，服务端兜到 6）时按前 8 条印；超过 1 页时整块换页，
  不会把图和列表切在两页。
- 分享页（只读链接）还没有这张纸：分享走的是另一套鉴权，这一轮没动。
- 评审记录上限 200 条、作品删除后评审解绑，这两条口径没变。
