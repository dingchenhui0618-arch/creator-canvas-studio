# 胶囊归队：13 种长得像胶囊的东西收回三档（v0.9.46）

日期：2026-11-13 · 版本：v0.9.46 · 上一轮：v0.9.45 按钮归队

## 一、问题：同一排里三种圆角、四种高度

这一轮和上一轮是同一类问题，只是换了个组件家族。按钮那次是字号被 reset 顶回 16px；
这次是**状态胶囊与标签各写各的**——`.vq-pill` / `.vq-tag` 早就收在 `shell.css` 里，
但页面上另有 9 个长得像胶囊的类，高度散在 16 / 20 / 22 / 23 / 24 / 26 / 28，
圆角散在 6 与 999，字号散在 11 / 11.5 / 12。生产 v0.9.45 实测（1440）：

| 页面 | 旧类 | 渲染出来的样子 |
| --- | --- | --- |
| 模板库 | `template-shared` × 26 | 高 **16px**、圆角 **6px**、11px 字（全站最小的一枚，方角） |
| 视觉评审 | `vq-chip` × 3 | 高 **24px**、999、11px |
| 视觉评审 | `vq-chip.is-verdict` × 3 | 高 **26px**、999、**12px** |
| 发现 | `status-pill` | 高 **28px**、999、**11.5px** + 6px 状态点 |
| 设置 | `vq-tag` / `vq-health-tag` × 11 | 高 20px、999、11px |
| 设置 | `vq-badge` | 高 **22px**、999、11px |
| 作品 | `vq-project-status` | 高 22px、999、11px |
| 作品 / 工作台 | `vq-delivery-tag` | 高 22px、圆角 **6px**、11px（版次） |
| 后台 | `admin-badge` | 高 **23px**（2px 内边距 + 1.5 行高）、999 |
| 画布 | `cv-run-badge` | 高 **24px**、圆角 **6px**、11px 等宽 |
| 智能体 | `agx-tag` | 高 20px、圆角 **6px**、11px |

最刺眼的一条：**圆角在表达「这是什么」时是反的**。运行状态（`cv-run-badge`）是方角，
公共模板标记（`template-shared`）是方角，而中性元数据（`vq-tag`）却是全圆——
同一排里方角与圆角混着出现，读者只能猜这枚形状是什么意思。

## 二、改法：三档尺寸 + 一套语气，尺寸进 token

改法和按钮那轮一样：**先立规范，再把页面搬到规范上**，而不是到处补 `!important`。

1. `tokens.css` 新增四组 chip token：状态 22px、结论 26px、标签 20px，水平内边距 8 / 6px，字号 11 / 12px。
2. `shell.css` 重写 `.vq-pill` 与 `.vq-tag`，成为**全站唯一**的胶囊与标签定义：
   - `.vq-pill`：22px 高、999 圆角、11px 等宽、`width: fit-content`、`white-space: nowrap`；
   - `.vq-pill--lg`：26px 高、12px 字，只给「评审结论」这种一页只有一个的判断；
   - `.vq-pill__dot`：6px 语气点（服务连没连上、示例数据模式）；
   - 七种语气只换颜色：`is-idle` 灰、`is-live` 黑、`is-pass` 绿、`is-warn` 琥珀、`is-fail` 红、`is-done` 反白、`is-mock` 金点；
   - `.vq-tag`：20px 高、999 圆角、11px 等宽、6px 内边距，给版次 / 分类 / 公共模板这类元数据；
   - 颜色一律读 token（`--pass-soft` 等），语气规则里**不写任何尺寸**。
3. `components/ui.tsx`：`StatusPill` / `MonoTag` 换成 `Pill` / `Tag`，语气名在 `pillTone()` 里归一，
   业务侧继续写 `ok` / `error` / `running` / `needs_review`，不用为了改样式改语义。
4. 9 个旧类名的尺寸定义**整段删掉**，页面级 CSS 只留布局（版次在台账里的位置、评审历史里撑满一格）。
5. 26 处调用改到 `Pill` / `Tag`：作品状态、评审页六处胶囊与严重度、评审历史行、发现页引擎状态、
   画布运行徽标、后台徽标、设置页健康与标签、两步验证徽标、智能体分类、模板公共标记、工作台版次。

## 三、顺手修的两件事（都是这轮改出来的）

- **窄屏把字挤成两行**：旧 `.vq-chip` 没有 `white-space: nowrap`，390 上它靠把「评审引擎 平台模型」折行来躲溢出。
  新胶囊是 nowrap + `flex: none`，页头三颗胶囊在 390 上会把页面顶出 94px 横向滚动。
  改法是让**整行**换行（`.review-head-status { flex-wrap: wrap }`），而不是让胶囊里的字折行。
- **胶囊被网格抻成长条**：胶囊作为网格项时默认 `stretch`，390 上「待开画布」被拉成一条空长条。
  给 `.vq-pill` / `.vq-tag` 加 `width: fit-content`，胶囊永远只包住自己的字。

## 五、边界

- 只动样式与组件层，没有动接口、计费、评审口径；这一轮没跑检索 / 解析 / 评审出片。
- `vq-filter-chip`（30px 筛选胶囊）没并进来：它是**可点的筛选器**，和只读的状态胶囊不是一类，
  尺寸与交互都不一样，合并会把「能点的」和「只能看的」混成一套。
- `.admin-tag`（后台内部环境的「真实接口 / 本地会话」标记）仍是独立样式，下一轮和后台按钮一起收。
- 圆角整站还没 token 化完：这一轮只把**胶囊与标签**这一族收到 999；卡片仍有 6 / 10 / 14 / 20 / 24 五个值，
  它们是 `--radius-*` token 的正确档位，页面上暂时没有随手数字。
