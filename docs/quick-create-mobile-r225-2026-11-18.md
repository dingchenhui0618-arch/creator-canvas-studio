# 快捷创作手机端：平台对话不再拖着预设库、切页签不再丢草稿（r225 / v0.9.209）

2026-11-18。清单第 10 项。改的是两件在手机上看得见、但一直没归类的事，都不涉及上游调用：
平台对话下面挂着的那一整块「已自建对话预设」，和切页签会丢草稿。

## 结论

1. **「平台对话」时页面下面还挂着整块「已自建对话预设」**。它跟当前这段对话没关系，
   却是手机上这一页最长的一段（390 宽 4 张卡就 979px），并且它把贴底的输入框顶出了视口——
   滚到预设卡片时，输入框已经在屏幕上方 −339px，「对话还没结束，输入框先跑了」。
   现在 ≤900 把这块收起来（挑预设走上面的「对话预设」页签，那里本来就是它的位置），
   桌面（>900）照旧显示，那块在桌面是这一页的主要内容。
2. **切页签会丢草稿**。「平台对话」面板原来只在 `对话 && 平台对话` 时渲染，切到「对话预设」
   或图片 / 视频就整块卸载：写了一半的提示词、附件、正在生成的回答一起没了。
   实测：输入「写了一半的提示词」→ 点图片 → 点对话，回来是空的。现在面板常驻、切走只 hidden。

## 改了什么

| 位置 | 改前 | 改后 |
| --- | --- | --- |
| `AgentsPage.tsx` 预设库 | 所有宽度、所有对话方式都渲染在对话下面 | 「平台对话」时加 `is-in-platform-chat`，≤900 收起；桌面照旧 |
| `agents.css` @≤900 | 无 | `.agx-library.is-in-platform-chat { display: none }` |
| `AgentsPage.tsx` 平台对话面板 | `{cond ? <QuickChat/> : null}`，切走即卸载 | 常驻 + `hidden`，新增 `chatMounted`（图片 / 视频切回对话时重新出现） |
| `agents.css` 面板壳 | 无 | `.agx-quickchat[hidden] { display: none }`——`.qc-root` 是 `display:grid`，hidden 属性在它身上不生效 |

## 数字（无头 Edge，同一份 dist + 手写会话记录 + 4 个种子预设）

| 宽度 | 页高（改前 → 改后） | 被收起的预设库 | 贴底输入框 |
| --- | --- | --- | --- |
| 390×844 | **2187 → 1176**（−1011，−46%） | 979px，4 张卡 | 滚到底时 672–820 仍在屏内；改前同一位置是 −339（已出屏） |
| 320×720 | **2490 → 1459**（−1031，−41%） | 999px | 484–696 在屏内（高 212px） |
| 1440×900 | 900 → 900（不变） | 586px，照旧显示 | 718–883（165px，未动） |

- 「改前」的数字是把这一块临时 `display: block !important` 放出来量的（布局等同改前），
  390 反事实页高 2187 与改动前真机实测一致。
- 切到「对话预设」页签：390 / 320 / 1440 下预设库都回来（`display: block`，979 / 999 / 586px，4 张卡）。
- 草稿：输入「写了一半的提示词」→ 图片 → 对话 → 值仍是「写了一半的提示词」；
  平台对话 → 对话预设 → 平台对话，值仍在。改前这两步都是空字符串。
- 390 / 320 整页 `scrollWidth` 分别等于 390 / 320，没有横向溢出。

## 边界

- 收起是**按宽度**的判断，不是按账号偏好：手机 / 平板竖屏（≤900）看不到预设库，
  要挑预设必须切「对话预设」页签；桌面行为完全没变。
- 面板常驻后，切走时**不会**中断正在进行的生成（之前卸载会断开）——本轮没有真实上游调用，
  这条只在假通道与本机实例上验证了「草稿还在」，没有验证「流式中切页签仍然写完」。
- 余额那行（26px）仍在输入框里：挪进会话条会让 390 宽的会话条更挤，而且会话条会滚走，
  余额反而在按下发送时看不见了，所以这轮不动它。
- 只改前端结构与样式，没有新接口、没动服务端与计费。
