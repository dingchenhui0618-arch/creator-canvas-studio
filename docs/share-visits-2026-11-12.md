# 分享链接被打开过几次：甲方看没看，不用再问（v0.9.10）

上线：2026-11-12，生产 visionqa.wavisionai.cn，版本 0.9.10。

## 为什么做这个

链接发出去之后，分享者心里只有一句「他看了吗？」。以前这个问题只能靠微信追问，
或者猜「没回就是没看」。这一轮把答案放回作品页：打开分享面板就能看到
**这条链接被打开过几次、最近一次是什么时候、从哪一类客户端打开的**。

它**不是**监控，也回答不了「是谁」「看了多久」：分享链接没有账号，本来就没有身份。
面板上写的是次数，不是人数；分享页自己也写明了「分享者能看到打开次数与最近一次时间，
不记录 IP，也不记录具体是谁」。

## 长什么样

作品页 → 分享 → 链接下面是「链接打开情况」一块：

- 有人看过：`2 次打开 · 最近 刚刚（手机或平板）`，下一行 `第一次打开 11-12 23:49`；
- 没人看过：`还没有人打开过这条链接。发出去之后回这里看，就能知道对方点开过几次、最近一次是什么时候。`

打开面板时会再取一次作品详情——这一步就是来问「看没看」的，不能拿开页面时的旧数字回答。

## 三个实现决定

1. **记录键是 token 的 SHA-256 前 16 位**，不存 token 本身。记录文件被谁看到都拿不到
   能打开作品的链接；对一个存着「客户链接打开历史」的文件来说，这点比省一次哈希重要。
2. **只记次数与客户端类别，不记 IP、不存原始 UA**。分类只有四种：微信内打开 / 手机或平板 /
   电脑浏览器 / 未知设备。够回答「甲方是微信里点的还是电脑上看的」，又不会变成一份访问日志。
   微信优先于手机判断：微信里点开也算「微信内打开」。
3. **60 秒内的连续打开算同一次**，窗口对着「上一次真正计数的那一次」算，不是对着最近一次打开：
   否则每隔几十秒刷新一次的人会让窗口一直往后滑，一晚上都只算一次。
   分享页一刷新就会再请求一次数据，不设窗口就会刷出假次数。

还有一个不做的事：**帧图与评审对照纸不单独记**。一次打开会带很多张图，
按图计数只会把「打开次数」变成「图片请求数」；这一版只记分享页本身被打开。

## 量到的

生产真实作品（8 镜 8 帧、2 次评审）实测：

| 动作 | 面板 / 接口读数 |
| --- | --- |
| 电脑上打开分享页 | `opens 1`，`lastClient desktop` |
| 同一分钟内手机再打开 | 仍是 `opens 1`，`lastAt` 前移、`lastClient mobile` |
| 过 62 秒再打开 | `opens 2`，面板写「2 次打开 · 最近 刚刚（手机或平板）」 |

- 面板 1440 宽 520px、390 宽 342px，两种宽度 `scrollWidth == clientWidth`，无横向滚动。
- 分享页页脚写明统计范围与「不记录 IP、不记录是谁」。
- 停掉分享后：分享页与 `/api/share/project/<token>` 都是 404，作品的 `share` 变回 null
  （记录本身留在数据目录里，是发生过的事）。
- 本地同一套流程（fixture 数据）先跑过一遍：1 → 同分钟仍是 1 → 过一分钟变 2。

## 边界

- **次数不等于人数**：没有账号就没有身份，两个人各开一次、一个人开两次，看起来一样。
- **只算分享页的数据请求**：直接打开评审对照纸、或用抓包工具只打帧图接口，都不计数。
  反过来说，不执行 JS 的抓取（微信生成链接预览那种）本来也打不到这个接口，不会刷出假次数。
- **记录上限 200 条链接**（按最近一次打开保留），超出后最早被忘掉；它是一份给人看的记录，
  不是审计日志。
- **停掉分享后记录不再显示**：面板随分享状态一起消失，记录仍在数据文件里。
  要做「历史链接」的界面，是下一轮的事。
- 数据文件是 `DATA_DIR/share-visits.json`，结构：`{ "<16 位哈希>": { opens, firstAt, lastAt, lastClient, countedAt } }`；
  `countedAt` 是「上一次真正计数的时间」，60 秒窗口对着它算，界面不读它。

## 复验命令

```powershell
# 本地：fixture 数据 + 演示模式，不需要登录
$env:DATA_DIR='.tmp-qa/r81-data'; $env:API_PORT='8789'; node server/index.mjs
# 打开分享页记一次（换 UA / 等一分钟分别看去重与新增）
curl.exe -s http://127.0.0.1:8789/api/share/project/<token>
# 作品页读到的统计
curl.exe -s http://127.0.0.1:8789/api/projects/prj_f38d68c6
```
