# 对不上之后做什么（v0.9.142，2026-11-15）

上一版说完「和上一次比变了哪一项」。可收据里仍然只有事实：差在哪一项、两边各写了什么。下一步要做什么，看的人还是得自己判断——是包被换了、没传全，还是他写反了。

这一版在逐项下面收一句：**这意味着什么，下一步做什么。**

## 五种差别，五句判断

| 差在哪 | 判断（加粗） | 下一步 |
| --- | --- | --- |
| 版次或包名 | 他验的不是这一版的包 | 先问他打开的是哪个文件，再把这一版的「交付包」和回执链接重发一次 |
| 字节数 | 他手上那份不是这个文件 | 多半没传全，或者解压后又压过：重发包，让他用包里那张「校验.html」重验 |
| 只有整包哈希 | 字节一样，内容不一样 | 重新压过或改过里面的字：重发包，让他重验 |
| 哈希空着 | 他那边没算出哈希 | 让他把 zip 拖进包里那张「校验.html」验完再导一张 |
| 贴回来的读不出来 | 他没验成：包在他那边读不出来 | 让他解压后用「校验.html」重验；再重发一份包更稳 |
| 包对上、结论写「有问题」 | 包对得上，只是他写的结论不一样（警示色） | 让他按逐项重贴一张，或你按逐项替他贴 |
| 这张没带逐项 | 对不上，但看不出差在哪 | 让他重新导一张收据 |

## 只在能证实的范围内说

- **不猜原因**：只说这种差别在收据上意味着什么（同一个名字、同样的字节，哈希不同 = 内容不是同一份文件），不说「他一定改过」。
- **对得上时一个字都不出现**：好消息不需要人再动手。
- **推不出来就说推不出来**：没带逐项的那张写「对不上，但看不出差在哪」，不硬塞一个最像的。
- **颜色只说轻重**：红 = 要重发或重贴，黄 = 包没问题、只是两边说法不一样；句子本身要能读。
- **只读**：没有新接口、没有新字段、没有新的写入路径——算的是 v0.9.136–139 存下来的五项与包里的记录。

## 坑

- **同一份文档里换 hash 时，旧页的节点还在**：只等「有建议」会读到上一页那一块（第一次运行就撞上，断言在「只贴过一次不该多出和上一次比」处炸出来）；要等只有新页才有的状态（收据结果那块是 is-broken）。
- **夹具里那三条 r149box 不是空的**：v2 本来就贴过一张读不出来的（r151 留下的），按「没有回执」去造数据会变成两次，多出一行「和上一次比」。先读接口再贴。
- **390 上这块在收据最底下**：截图要把这一块滚到正中，否则只拍到收据上半截。
- **文案里点按钮要叫得准**：「上面那个「交付包」」就是同一行右上角那个下载按钮，不另做一个按钮。

## 发现但没做

- 不替你写发出去的那段话（要发微信 / 邮件还得自己复制一句）。
- 工作台那一行仍只有结论，看不到「下一步做什么」。
- 收包人那一侧（免登录的回执地址）还是只说这一次。
- 「重发这一版」仍是两步手点，没有一键重发。
