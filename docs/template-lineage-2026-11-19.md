# 「改编自 tpl_xxxxxxxx」不该出现在界面上：模板详情里的来源都能点回去（r254 / v0.9.237）

日期：2026-11-19。

r252/r253 之后，从评审回落下来的模板越来越多，它们身上都带一个 `adaptedFrom`——
「这一版是从库里哪条模板传下来的」。抽屉里原来把这个字段直接印出来：

```
… · 模板 tpl_386d97a8 · 改编自 tpl_r253probe
来源：改编自模板 tpl_r253probe · 原片的作者、链接与互动数据不复制
```

一串原始 id 用户认不出是哪条，也点不过去。这一轮把它换成来源那条的**标题**，并给一个能点过去的出口。

## 改了什么

| # | 位置 | 以前 | 现在 |
| --- | --- | --- | --- |
| 1 | 详情接口 `GET /api/templates/:id` | 只回 `adaptedFrom`（id） | 多回 `adaptedFromTitle`：在「当前账号看得见的那份列表」里现算，找不到就回空串 |
| 2 | 抽屉副标题 | 「· 改编自 tpl_xxx」 | 「· 改编自《毛衣折叠收纳法（原片）》」；查不到写「· 改编自另一条模板」 |
| 3 | 抽屉「来源」块（改编版） | 「改编自模板 tpl_xxx · …」纯文字 | 「改编自《…》· 原片的作者、链接与互动数据不复制」+ **打开这条模板** 按钮 |
| 4 | 来源已删 / 不在当前账号下 | 仍然印一个 id | 「改编自另一条模板（原来的那条已删除或不在当前账号下）」，不给按钮 |

标题现算的规则写在新函数 `adaptedFromTitle(template, list)`：只在 `listTemplates()` 那份**已经过归属过滤**的列表里找，
所以既不会把 id 冒充成标题，也不会把别人的模板标题漏给当前账号。

## 证据（本机临时实例 + 无头 Edge 真鼠标，0 次真实上游调用）

三条真形状的模板：一条原片、一条改编自它、一条改编自已经删掉的 id。

| 项 | 结果 |
| --- | --- |
| 详情接口 | `{adaptedFrom: 'tpl_r254origin', adaptedFromTitle: '毛衣折叠收纳法（原片）'}` |
| 来源不存在时 | `{adaptedFrom: 'tpl_gone_404', adaptedFromTitle: ''}` |
| 1440 抽屉副标题 | 「口播脚本与分镜 · 0:19 · 模板 tpl_r254adapt · 改编自《毛衣折叠收纳法（原片）》」 |
| 1440 来源块 | 「改编自《毛衣折叠收纳法（原片）》 · 原片的作者、链接与互动数据不复制」+ 打开这条模板（121×28） |
| 真点「打开这条模板」 | 地址 `#/templates/tpl_r254adapt` → `#/templates/tpl_r254origin`，抽屉换成「毛衣折叠收纳法（原片）」 |
| 来源已删 | 副标题「· 改编自另一条模板」；来源块「改编自另一条模板（原来的那条已删除或不在当前账号下）」，无按钮 |
| 390 | 来源块宽 357，按钮 127×44 整行可点；innerWidth 390 = scrollWidth 390，溢出 0 |

## 边界

- 标题是**现算**的：来源被删、被移进回收站、或不在当前账号下，抽屉就只能写「另一条模板」——
  这一条不落库，所以来源改标题之后这里跟着变，是想要的。
- 「打开这条模板」只在标题查得到时给；查不到时按钮不给，免得点了 404。
- 只改详情接口多一个字段与那一块文案：列表、卡片、筛选、作品页都没有动；
  卡片脚注上的「来自作品 / 改编版」等来源标签口径不变。
- 探针只验这一个字段与这一块交互；本轮真实上游 0 次、0 费用。
