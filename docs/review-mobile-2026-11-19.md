# 视觉评审页窄屏：小字 13px、点按区 40/44px（r239 / v0.9.223）

2026-11-19。第 21 条 UX 清单项。上一轮（r238）把设置页从 69 处小字 / 18 处小点按区清到 0，
视觉评审成了剩下最差的一页：390 宽首屏 22 处 12px 的字、4 处不到 40px 的点按区，
一条历史评审详情 40 / 6，历史弹层 35 / 6。

## 结论

| 宽度 | 首屏（候选 + 最近评审） | 一条历史评审详情 | 历史弹层 | 页面高度 |
| --- | --- | --- | --- | --- |
| 320 | 22/4 → **0/0** | 40/6 → **0/0** | 35/6 → **0/0** | 2295/3318 → 2354/3472 |
| 390 | 22/4 → **0/0** | 40/6 → **0/0** | 35/6 → **0/0** | 1963/2907 → 2016/3056 |
| 768 | 22/4 → **0/0** | 40/6 → **0/0** | — | 1575/2407 → 1607/2470 |
| 1024 | 23/3 → **0/0** | 41/5 → **0/0** | — | 900/900（外壳内部滚动，同改前） |
| 1440（不动） | 30/18 → **30/18** | 45/20 → **45/20** | — | 900 → 900 |

「22/4」= 小于 13px 的文字 / 不到 40px 的点按区。1440 是逐元素比对：
两次量的选择器、字号、宽高完全一致（`identical: true`）。

## 改了什么

评审页的字号与点按区几乎全走 shell 的原子（`.vq-pill` / `.vq-tag` / `.vq-mono` / `.vq-button`），
所以主体做法是**在 `.review-page` 上把原子档位抬一档**，不碰其它页共用的默认值。
规则全部写进 `src/styles/review.css` 末尾两段媒体查询（≤1080 / ≤560），桌面 1081 起一条都不进。

| 位置 | 改前 | 改后（≤1080 / ≤560） |
| --- | --- | --- |
| 状态胶囊（需人工确认 / 通过 / 不通过 / 未通过） | 12px，高 22 | **13px，高 24** |
| 问题严重度标签（主要 / 阻塞 / 次要 / 信息） | 12px，高 20 | **13px，高 24** |
| mono 小字（时间、版本、面积、置信度、模型与耗时） | 12px | **13px** |
| 历史行的「作品 · 第几版」与撤回/孤儿标记 | 12px | **13px** |
| 问题编号盒（01 / 02 …，画面上的锚点） | 12px，盒 16×16 | **13px，盒 18×18** |
| 「4 个模板首帧」折叠开关 | 12px，高 24 | **13px，高 40 / 44** |
| 「查看全部 4 条」「还有 N 条」 | 35px 高 | **40 / 44px** |
| 历史行（列表与弹层） | 4–8px 内边距、约 34px | **min-height 40 / 44px** |
| 「选图」「回作品」「评这一版」等小按钮 | 28px | **40 / 44px** |
| 顶栏图标态搜索（骨架，全站） | 30×40 | **40×44（40×40 / 44×44）** |
| 侧栏「等你看」计数（骨架，1024 展开时可见） | 12px | **13px** |
| 顶栏图标按钮 / 弹层关闭按钮（320） | 被挤到 39 / 38px 宽 | **不参与收缩，44px** |

## 边界

1. 只量 Chromium（Edge 157）无头、1x；没在真机触屏、Safari、Firefox 上验证。
2. 量了 320 / 390 / 768 / 1024 / 1440；561–767、769–1079 没逐档量（规则按 1080 / 560 两个断点统一）。
3. 空态（还没有作品、刚进评审页的引导卡片）与排队条（`.review-queue-strip`）这一轮没截图：临时实例里造不出真实排队，
   这些类的字号在 ≤1080 里也一并抬到 13px，但没有界面证据，只有样式与单测。
4. 顶栏搜索、侧栏计数是**全站骨架**，改的是 `.vq-search`（≤900 图标态）与 `.vq-nav-item em`（≤1080）；
   其它页在窄屏下也跟着变，这些页本轮没逐页复量。
5. 只有取点按区「宽或高 < 40px」这一条判据；点按区之间是否互相遮挡、是否在滚动容器外，本轮没做几何检测。
6. 截图里的作品名、评审结论、判断模型数字都是样例数据，不是生产账号的真实评审。
7. 本轮 0 次真实上游调用：没有出图、没有出视频、没有跑视觉评审（临时实例里的评审记录是直接写的 JSON）。
