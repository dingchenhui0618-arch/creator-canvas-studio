# 评过不等于过了：作品状态胶囊直接写评审结论（v0.9.19）

**结论**：作品卡片、作品页、工作台三处的状态胶囊不再一律写「已评审」。
这一版评审有结论时，胶囊直接写结论——「评审 · 通过」「评审 · 需人工确认」「评审 · 不通过」，
颜色跟着语气走。工作台多一块「评审等你看的」：当前这一版最近一次结论是需人工确认或不通过的作品，
按评审时间排队，点一条就进作品改一版；「下一步」主卡也先挑队列里最该动手的那条，按钮写「按意见改这一版」。
作品页在评审通过时，下一步不再是「继续画布」，而是「交付这一版」，点了直接打开交付菜单。

## 之前 / 之后

| 之前 | 之后 |
| --- | --- |
| 评过 1 次和评过 9 次、通过和不通过，卡片上都写「已评审」 | 胶囊直接写结论：评审 · 通过 / 需人工确认 / 不通过，三档颜色 |
| 想知道「这条过了没」得点进作品页翻评审面板 | 作品列表第一眼就看得到，鼠标放上去还有「需人工确认 · 11/12 18:03 · 评过 2 次」 |
| 工作台只回答「最近在改哪条」，评审给出意见的作品不露面 | 工作台多一块「评审等你看的」，按评审时间排，点一条进作品 |
| 工作台「下一步」可能挑到一条已经通过的 | 先挑队列里最该动手的；通过的作品不进队列 |
| 评审通过后主卡还写「按评审意见改一版」 | 通过时写「这一版评审通过了」，按钮「交付这一版」直接开交付菜单 |
| 交付稿纸上写「状态：已评审」 | 纸上写「状态：评审 · 需人工确认（当前第 2 版）」 |

## 三个决定

1. **状态胶囊不再说「已评审」**。「评过」和「过了」是两件事，而「已评审」把这两件事混成了一句没有信息的话。
   现在有结论就写结论，只有结论之前的老记录（没有 verdict 字段）才退回「已评审」——不假装它给了结论。
   文案与评审页、评审历史、分享页用的是同一套字（通过 / 需人工确认 / 不通过），只多了一个「评审 ·」前缀。
2. **队列放在服务端一处算**。`GET /api/reviews/queue` 只看**当前这一版**：版本划分之前记在 0 上的评审折进 v1
   （与状态胶囊同一套折进规则），最近一次结论是需人工确认 / 不通过的才进队列，按那次评审的时间倒序；
   **已交付的不再催**（都交出去了），**通过的也不进**（不需要动手）。工作台的「下一步」主卡与「评审等你看的」
   读同一份结果，不各自去猜。
3. **口径只有一个 service 模块**。作品的四种状态与「某一版评过几次」收在 `server/project-status.mjs`，
   交付稿（Markdown / 打印纸）与前端 `src/domain/project.ts` 各读一份同样的规则；
   以前交付稿里那份私有 `statusLabel` 已删掉，纸上的状态与页面上那枚胶囊不会再各说各话。

## 口径

- **只看当前版**：作品 v2 有意见就报 v2，不拿 v1 的旧结论冒充；v1 的评审用在版本对照里。
- **折进规则**：版本划分之前（version 0）的评审在 v1 上一起算——老作品不该显示成「没评过」。
- **队列排序**：按当前这一版最后一次评审的 createdAt 倒序，同一时间按 projectId 兜底，保证顺序稳定。
- **状态优先级**：已交付 > 待开画布 > 在做（当前版没评过）> 评审结论 > 已评审（老记录没有结论）。
- **总数与一页**：队列一页最多 20 条（服务端截断），工作台只取前 3 条并用 `total` 写标题下的说明。

## 顺手修

1. **卡片右上角的时间不再被拆成两行**：胶囊变长后，「11-12 18:34」在 390 宽上被挤成「11-12 / 18:34」两行；
   现在时间 `white-space: nowrap` 不参与挤压，胶囊自己换行。
2. **队列行的胶囊固定一列**（128px）：三档文案长短不一，作品名必须从同一条竖线开始。
3. **窄屏队列行改成两行**：胶囊挪到作品名上面，否则「第 1 版 · 评过 8 次 · 11/13 00:40」会被挤成三行。
4. **状态胶囊样式从 projects.css 收进 shell.css**：工作台也在用它，不再只属于作品页。

## 边界

- 队列只收「当前这一版最近一次结论是需人工确认 / 不通过」的作品；**已交付**与**已通过**都不进队列。
- 队列没有「划掉 / 已看过」状态：不想看到它，只能改完再评一次，或把作品标记交付。
- 工作台只取前 3 条，更多要去「全部评审」；队列一页上限 20 条。
- 状态胶囊看的是**当前版本**：老版本的结论在作品页的「版本对照」里看。
- 结论之前的老记录仍显示「已评审」——它确实没有结论，不补一个。
- 没有加通知、没有加角标计数：这一轮只把状态摆到看得见的地方，推不推送还没定。
