1. 本地 `npm run build`（tsc + vite build），确认 `dist/assets/AdminConsolePage-*.js` 里已经有「识别为」这句新文案；
2. 打包 `tar -czf vq-r182.tgz dist server scripts package.json deploy`（1.34 MB）；
3. `scp` 到 `/tmp/vqdeploy-r182.tgz`，在服务器解开到 `/tmp/vqstage-r182`；
4. `bash /tmp/vqstage-r182/scripts/deploy.sh /tmp/vqdeploy-r182.tgz "20261117-1332-r182"` —— 脚本先给当前版本打快照，再替换 `dist / server / scripts / package.json`（`data` 不动），然后重启并自检健康。
