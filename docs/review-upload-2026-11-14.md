# 传一张自己的图直接评（v0.9.87）

一句话：评审的第一个入口不再是「先建作品」——把图拖进来、或者直接 Ctrl+V 贴一张截图就能评；这张图只属于传的人。

## 为什么

在这之前，「视觉评审」能评的画面只有两种来路：已经躺在数据目录里的图（模板首帧、画布帧），或者一个公网图片地址。作品页那句「把这一版要发的画面贴进来最准」一直没有入口能把图放进来——文案在邀请一个做不到的动作。

而做视觉 QA 的人最自然的一步是「我有一张图，你帮我看看」：这个动作不该要求先建一条作品，也不该先在画布上出一张图（出图要花积分）。所以这一版补的是入口本身，不是新的评审能力：评审那条链路一个字没改，认的还是 `media` 路径。

## 做了什么

1. **`POST /api/media/upload`**：请求体就是文件本身（原始字节，不是 JSON、也不是 multipart——multipart 要在服务端再解析一遍边界，解析器本身就是一块内存和一片攻击面）。按**文件头**认 jpg / png / webp，不看扩展名、也不信 `Content-Type`；单张 ≤ 8 MB（与评审入口同一个上限）。
2. **落盘**：`uploads/<账号 id>/<时间戳>-<随机 12 位>.<ext>`，服务端起名、只认这个形状。每个账号最多留 20 张、合计 160 MB，再传就顶掉最旧的那张——没有任何清理入口时，无上限等于把磁盘交给上传的人。
3. **`GET /media/uploads/<账号>/<文件>`**：必须登录，只能读自己的（管理员可读全部）；别人的路径回 **404**，连「这个文件在不在」都不告诉；响应带 `nosniff` 与 `Cache-Control: private, max-age=300`。
4. **评审入口的归属闸**：`uploads/` 开头的图要核账号，别人的图评不了（`404 MEDIA_FORBIDDEN`）。这道闸放在扣费与并发名额**之前**：被拒的这一单不扣积分、不占名额。
5. **来源分开记**：评审记录的 `source.kind` 从「凡是 media 都记 template」改成 `upload` / `template` 两种——不然后台与纸面会把一张上传的截图说成模板帧。
6. **界面**：评审页「单独评一张画面」栏里加了三种入口——拖进来、Ctrl+V 贴截图、点「选图」。传完直接选中，后面的评审与原链路完全一致；大小与类型在本机先拦一次（省得 8 MB 白传），服务端再按文件头判一次。
7. **请求体**：新增 `readBinaryBody`，三道闸与 JSON 那条完全一样（`content-length` 声明就超了不读、读到一半超了不再拼、超过 4 倍断连接），只是不解析成字符串。

## 坑

1. **nginx 给 `/media/` 加了 7 天 public 缓存头**（模板帧需要），上传图跟着走会被中间层当公开资源存 7 天。改成在 `/media/uploads/` 前面插一个 `location ^~ ` 块，缓存头交给应用（`private`），`nginx -t` + `systemctl reload nginx`，配置备份在 `/root/visionqa.wavisionai.cn.conf.bak-r98`。匿名实测 401 且只有 `no-store`。
2. **评审入口只校验「图在数据目录里、是图」，不校验「是不是你的」**。上传目录按账号分之后，这条缝能让人拿别人的路径去评（虽然要先猜到随机文件名）。补了归属闸，并把它放在扣费与名额之前。
3. **来源记成 template**：以前凡是有 `media` 就记 `template`，上传的截图在记录、纸面、后台里都会被说成「模板帧」。现在分开。
4. **评审对照纸画不出上传图的框**：纸只认 `frames/<模板 id>/<文件>`；上传图会印「这次评审的画面不在我们的帧图里」，框不画、问题与编号照排——不假装有图，也不把框叠到空框上。
5. **限流按 IP 计数**：本地把 13 次真发出去才看见 429；「被 415 拒的那一次」也算在限流里（它在路由之前就计数了），写断言时别忘了。
6. 上传图不进「素材占用」那本账（那一本按模板帧算）：它有自己的 20 张 / 160 MB 上限，见上面第 2 条。两本账不混。

## 发现但没在这一轮做

`/media/frames/<模板 id>/<文件>` **仍然可以匿名读取**（生产实测 200）：应用侧只校验路径，模板帧那条没有登录门。模板帧多数来自公开视频，但用户自己复刻的视频帧也落在同一个目录。修它要连带确认分享页的帧（分享页已经是 token 地址 `/api/share/project/<token>/frame/<i>`）与「公共模板对所有登录用户可见」的规则，单独一轮做，不跟上传混在一起。

## 边界

- 只收 jpg / png / webp；gif、svg、heic 不收（按文件头判，改名的 html 也进不来）。
- 20 张 / 160 MB 会顶掉最旧的：旧评审记录还在，只是那张原图可能已经没了——评审页本来就按这个情况写文案（「证据原图被删过」）。
- 上传本身不扣积分（它只是存储）；评审照旧按次扣。
- 图不给别人看、不进分享页、不进交付包；管理员排障可读。
- 回退：`bash /opt/visionqa/ops/rollback.sh --to 2`（回到 v0.9.86）。纯加法：老前端不调用新接口，老数据里也没有 `uploads/` 路径，回退安全。

测试 **766 / 766**（+11 `test/upload-media.test.mjs`），oxlint 0 error / 15 warning，`tsc -b` 干净，密钥扫描 594 个文件 0 命中。
