# VisionQA 的两个形态

日期：2026-11-09 · 状态：对外只有生产版；后台版改为地址栏进入

同一套设计语言（ink 单色、发丝线、Geist + Noto Sans SC）。

## 用户生产版 / PRODUCTION

对外唯一形态，就是这一版工作台：

| 分组 | 页面 |
| --- | --- |
| 主层 | 工作台 / 爆款雷达 / 模板库 / 智能体 / 画布 / 视觉评审 |
| 设置层（横线下） | 运行记录 / 设置 |

侧栏里**没有**形态切换：客户不需要知道系统还有后台版。之前的「资产库」入口整页删除（6 条假资产 + 假统计，没有后端）。

## 后台管理版 / ADMIN

运维自己用。入口是地址栏 `?edition=admin`（记在 `vq.edition`），进去后侧栏有一条「返回生产版」。

| 分区 | 内容 | 数据来源 |
| --- | --- | --- |
| 总览 | 模板数、运行数、依赖状态；用户数没有接口就写「—」 | `/api/templates` `/api/runs` `/api/health` |
| 账号 | 当前会话（邮箱 / 显示名 / 角色 / 工作区 / 登录时间）+ 还缺哪三个接口 | 本地会话缓存，页头写明「未接后端用户表」 |
| 模型 Key | 红狐 / 视觉模型是否配置（只显示布尔，不显示值） | `/api/health` |
| 模板治理 | 模板列表、关键词过滤、删除 | `/api/templates`（DELETE 真实生效） |
| 运行审计 | 运行记录倒序、逐节点输出 | `/api/runs` |
| 系统 | 版本、启动时间、VisionQA Canvas 三端口 | `/api/version` `/api/bdc/status` |

## 已删除：内测测试版 / LAB

2026-11-09 整块删除（`src/pages/lab/`、`src/styles/lab.css`）。它原来的四页是：

| 分区 | 当时的问题 |
| --- | --- |
| 接口体检 | 有价值，但属开发调试工具，不该随产品发出去 |
| 样例对照 | 专门把 `src/data/mock.ts` 的假数据摆在真实接口旁边——假数据本体已删，对照页失去意义 |
| 功能开关 | 三个开关全部标注「仅记录，尚未接线」，没有任何模块读取 |
| 诊断导出 | 版本 + 浏览器信息 + 控制台记录，排障用；需要时用浏览器开发者工具 |

## 为什么这样切

1. **用户不该看见审计和 Key。** 生产版导航里没有任何管理项；后台入口不在界面上，不靠「藏按钮」。
2. **后台版必须能追责。** 模板治理、运行审计都是真实读写，删除模板会真的删（有二次确认）。
3. **没有数据就写没有。** 后台每个数字标「真实接口 / 本地会话」；没有用户列表接口时显示「—」并写明原因，不摆假数字。

## 还没做的

- 两个形态共用一个登录会话；真正的角色权限（管理员/普通用户）要等后端用户表。
- 后台的「账号」只能读当前会话；缺 `GET /api/admin/users`、禁用/重置口令接口与审计日志落库。
- VisionQA Canvas 同机部署后，生产版的画布会切到 VisionQA Canvas（见 `docs/visionqa-canvas-integration.md`），后台系统页显示三端口状态。
