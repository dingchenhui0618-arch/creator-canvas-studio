# 作品列表：找得到、筛得动（v0.9.23，2026-11-13）

结论先行：**作品列表从「按改动时间堆着」变成「能找、能筛、数字是真的」**——
搜作品标题或模板名，按「在做 / 已交付」筛，三枚胶囊各自带计数；
筛选与计数都走服务端，与状态胶囊、交付记录同一套口径。只读，不写数据、不调模型、不扣积分。

## 一、为什么做这一片

作品是主线对象（P1 落地），但它的入口一直只支持「作品少」的情况：

- 列表只按最近改动排序，找一条旧作品只能滚；26 条模板意味着至少能长出 26 条作品。
- 状态胶囊已经有 7 种写法（待开画布 / 在做 / 评审 · 通过 / 需人工确认 / 不通过 / 人工通过 / 人工不通过 / 已交付），
  但列表没法按状态筛，交付过的和还在改的混在一起。
- 工作台回答「下一步点哪里」，不负责「上周那条毛衣折叠放哪了」——这件事只能列表自己回答。

## 二、规则（6 条）

1. **搜索范围只有卡片上看得见的两行**：作品标题 + 模板标题。搜不到的东西不假装能搜到（不匹配钩子、台词、评审正文）。
2. **多个词是「都要命中」**（AND），空格分隔；大小写不敏感；全角空格也认。最多取前 5 个词、每词最多 40 字。
3. **三种筛法：全部 / 在做 / 已交付**。分桶只回答「当前这一版交没交出去」，口径是 `deliveredCurrent`：
   交付了 v2 又开 v3 的那条算在做；老数据 `status=done` 但没有交付记录，照旧算已交付（时间没记录）。
4. **分面计数按关键字算、不按当前状态算**：换了状态，另一排数字仍然是真的（与评审历史 v0.9.18 同一套）。
5. **关键字归一后回显**：小写、多个空格收成一个；界面用它判断「有没有在筛」。
6. **接口向后兼容**：不传 `q` / `state` 就是原来的列表，只是多返回 `shown` / `facets` / `query` / `state` 四个字段。

## 三、界面

- 页头下一条工具栏：搜索框（占住左侧，宽 340px 封顶）+ 三枚筛选胶囊（计数在字后面，等宽小字）+ 右侧「共 N 条」。
- 有筛选时右侧变成「筛出 3 / 共 9 条」，多一个「清掉筛选」；空结果给「没有符合的作品」，按钮「清掉搜索与筛选」。
- 两种空状态分开：账号里一条作品都没有（去模板库挑一条）与筛不出来（换个关键词 / 清掉筛选）。
- 顺手键：列表页按 `/` 聚焦搜索、在搜索框里按 `Esc` 清掉关键字；正在输入的地方不抢键。
- 「刷新」保留当前筛选；窄屏搜索框独占一行，胶囊与计数自动换行。

## 五、本地演示数据（9 条作品，非生产）

- 默认：全部 9 / 在做 6 / 已交付 3，「共 9 条」；卡片上同时出现已交付、评审 · 不通过、评审 · 通过、待开画布、在做。
- 搜「咖啡」：全部 3 / 在做 1 / 已交付 2，「筛出 3 / 共 9 条」——命中的是 1 条标题 + 2 条模板名（模板 · 咖啡店探店模板）。
- 再点「已交付」：筛出 2 / 共 9 条，两张卡都写着已交付。
- 关键字改成「不存在」：筛出 0 / 共 9 条，胶囊计数全归 0，空状态出现。
- 点「清掉筛选」：回到「共 9 条」。
- 键盘：`/` 聚焦搜索（占位「搜索作品或模板名」），输入「毛衣」后 `Esc` 清掉，回到「共 9 条」。
- 1440 工具栏 1130×32；390 工具栏 290×92（带「清掉筛选」时 102），两档都无横向滚动。

## 六、边界

- 筛选不写进地址：刷新回到全部、也不生成「筛好的链接」——地址只寻址对象，不寻址视图。
- 不能按分享状态、版本号、时间范围筛；不做保存的筛选视图。
- 搜索不碰钩子、台词、评审正文与运行记录，只认卡片上那两行。
- 计数是「账号下看得见的作品」，不跨账号、不含已删除作品。

## 七、复现

```bash
# 本地演示数据（9 条作品 / 4 条模板），不起登录
node .tmp-qa/r94-seed.mjs
$env:DATA_DIR='.tmp-qa/r94data'; $env:API_PORT='8898'; $env:VQ_REQUIRE_AUTH='0'; node server/index.mjs
# 打开 http://127.0.0.1:8898/#/projects：搜「咖啡」、点「已交付」、清掉筛选
```

## 八、文件

- `server/project-list.mjs`（新）：分词、搜索范围、分桶、分面计数、筛选；纯函数，无 IO。
- `server/routes/projects.mjs`：`GET /api/projects` 读 `q` / `state`，返回 `shown` / `facets` / `query` / `state`。
- `src/api/projects.ts`：`listProjects({ q, state })`，参数只在有值时拼上。
- `src/domain/project.ts`：`ProjectBucket` / `ProjectListFacets` 两个类型（分桶口径与状态胶囊同源）。
- `src/pages/ProjectsPage.tsx`：工具栏、计数、两种空状态、`/` 与 `Esc`、刷新保留筛选。
- `src/styles/projects.css`：工具栏 / 搜索框 / 计数 / 清掉筛选，全部走 4/8pt 与圆角 token。
- `test/project-list.test.mjs`（新，11 条）：分词、标题与模板名命中、AND、空白关键字、交付口径、分面、坏状态、归一、5 词上限、不改入参。
