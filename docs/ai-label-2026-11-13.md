# AI 生成内容标识：四种出口都带上（2026-11-13，v0.9.57）

## 一句话

《人工智能生成合成内容标识办法》2025-09-01 施行，平台生成的内容必须标出来。以前只有后台文档里写着「待做」；这一版把 **交付稿（Markdown）、A4 交付稿、现场页、评审对照纸、只读分享页** 五个出口全补上显式标识 + 说明，纸张源码里另带隐式标识的 meta；同时把隐私说明的第三方处理者清单写实、条款版本随内容一起升到 2026-11-13。

## 为什么是现在

- **法规**：办法要求生成合成内容服务提供者对生成内容添加显式标识（看得见）与隐式标识（元数据）。我们生成脚本、分镜、评审结论，产物一旦交给剪辑 / 制片 / 甲方，就离开了平台的控制范围。
- **产品**：「这条作品出了工作台」正是交付链路（交付稿 → 打印稿 → 现场页 → 评审对照 → 分享链接）的终点，标识不跟着产物走，等于把合规责任丢给收件人。
- **现状证据**：本轮之前 grep「AI 生成」全仓只有 docs/launch-readiness-2026-11-12.md 里的一行待办，界面与产物里一处都没有。

## 做了什么

| 出口 | 显式标识（人看得到） | 隐式标识（机器读得到） |
| --- | --- | --- |
| Markdown 交付稿 | 抬头第一段后一行引用：`> **AI 生成**：…发布前请人工核对事实、人名与数据。`；落款追加「AI 生成 · VisionQA」 | 说明文字本身（纯文本出口，无 meta） |
| A4 交付稿 | 品牌行右侧「AI 生成」胶囊 + 正文引用块（来自同一份 Markdown） | `<meta name="ai-generated" content="true">`、ai-generator、ai-label、ai-label-version |
| 现场页（脚本 + 分镜） | 品牌行胶囊 + 抬头事实下的说明句 + 纸脚「AI 生成 · VisionQA」 | 同上四条 meta |
| 评审对照纸 | 品牌行胶囊 + 说明句 + 纸脚「AI 生成 · VisionQA」 | 同上四条 meta |
| 只读分享页 | 标题行状态下方的「AI 生成」胶囊；底部一块标识说明（label + notice + 法规名） | 分享接口 `GET /api/share/project/<token>` 白名单新增 aiLabel 字段 |

几个刻意的决定：

1. **一份措辞，五处复用**：新模块 `server/ai-label.mjs` 出 AI_LABEL_NOTICE / aiLabelMeta / aiLabelMarkdown / aiLabelMetaTags / aiLabelBadge / aiLabelFootText，纸张通过 brandRow() 统一排版。标识文案改一处，五个出口一起变，不会出现「纸上一个说法、分享页另一个说法」。
2. **只标事实**：标识只说「谁生成、按哪一版规则标、发布前要人工核对」，**不写「已人工审核」**——有没有人拍板，交付稿抬头「人工复核」与评审纸纸脚各写各的，标识不替它们下结论。
3. **错误页不挂标识**：printNoticeHtml（「打不开这张稿」）明确不加 meta 与胶囊。把登录过期这种错误页说成 AI 生成内容，是另一种误导。
4. **提示入口先讲清**：作品页「交付」菜单里加一句「每份产物都带『AI 生成』标识与说明」，导出前就知道产物的固定成分，不会以为是这次的附加项。

## 顺带补上的两处合规文案

- **隐私说明 → 三、第三方处理者**：原来只写「平台配置的大模型服务商」。现在按代码里真实的通道写实（2026-11-13 配置）：DeepSeek（文本与视觉识别）、SeeAPI 生成服务（画布出图 / 出视频）、红狐（公开平台素材检索），并写清「请求内容会离开平台服务器」。
- **隐私说明 → 七、AI 生成内容** 与 **服务条款 → 六、AI 生成内容标识**：写清标识出现在哪几处、不代表人工审核、去掉标识再发布由发布者负责。
- **条款版本升到 2026-11-13**（`server/config.mjs` 默认值）：注册时记录同意的版本，条款改了就换版本号，这样账号上「同意的是哪一版」能对得上。

## 这轮没做的（不夸大）

- **生成图片 / 视频本身的元数据**：画布出图由 SeeAPI 返回，平台只在转发层；给图片烧水印或写 C2PA 需要改画布渲染与上游返回处理，属于 C1 的事，本轮没碰，也没对上游发任何生成请求。
- **主体信息**：隐私页仍写「平台配置的服务商」，不写公司全称 / 地址 / 信用代码——这些只有你能给（A7 剩余项）。
- **ICP 与客服邮箱**：`/api/app` 里仍是空字符串，页脚如实显示「工作区管理员」。
- **生成式 AI 备案 / 算法备案**：流程动作，代码层面已经按办法做了标识，登记进度需要走属地网信办。
