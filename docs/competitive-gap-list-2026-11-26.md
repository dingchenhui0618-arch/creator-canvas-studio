# 竞品对比与我们缺什么（2026-11-26，讨论稿 v1）

对比对象：**即梦AI（字节）**、**LibTV（liblib.tv，与 LiblibAI 同一家）**、**RunningHub**、**PixArt**、**picsetai.com（Picset，已改名 Picell AI）**。
分工：四份原始调研与出处表在文末「原始材料」；本文件只做**去重、排序、落到我方现状**。
出处分档：A=官网/官方文档明说；B=官方公告转载或第三方实测；C=传闻/未核实。**没核实的一律写未核实，不猜。**

## 0. 先说三个共性致命缺口（三家公司从三个方向同时戳到）

### 0.1 我们说不出「一条多少钱」，而且充值通道是关的、内测直充还会白送

| | 竞品怎么做的 | 我们现状（证据） |
| --- | --- | --- |
| 对外价格 | 即梦首页直接挂单秒价：Seedance 2.5 低至 **¥0.16/秒**，7 档年卡 ¥393~¥19656，并把「¥10 = 192~328 积分」写在档位卡上 [A] | `server/media-pricing.mjs` 只有内部公式（上游成本 ×1.1 ×10 积分/元），**对外说不出单条价** |
| | LibTV 横幅：Seedance 2.5 720P **0.16 元/秒**、年卡每秒最低 5 分钱 [A] | 积分单价是内部四个数字（检索 2 / 复刻 10 / 评审 5 / 对话 1） |
| | RunningHub：一条 15 秒商品口播实测 **260–294 点 ≈ US$0.22/条**，另有点数包（31 天清零）[B] | 档位在 `server/plans.mjs` 里能后台改，但没有支付、没有对账、没有发票 |
| | Picset：**$5/月起**（第三方口径，官网 /pricing 是 SPA 抓不到）[B] | `VQ_BILLING_MODE` 默认 `auto`：点档位就标 paid 并到账（`server/routes/billing.mjs`）——**注册一开放等于白给积分** |

**判断**：这不是价格高低问题，是**没有对外价格语言**。补的动作很具体：① 把 `auto` 关掉，内测直充只留管理员/白名单；② 对外价目表按「单秒 / 单条 / 每次评审」三档写出来；③ 支付（商户号）与对账、发票另立一轮。

### 0.2 复刻链最假的一步：我们没有音轨、没有 ASR、没有 BGM

- **LibTV 有一模一样的功能，而且是真的**：它的「视频解析」对成片做分镜拆解，输出**画面内容、景别、图像提示词、运镜提示词、时长、音乐节奏、人声**的表格 [B]。
- **我们**：抽帧时用 `-an` 把音轨丢掉（`server/frames.mjs:58`），提示词却要求「即使没人声也给建议口播」（`server/vision.mjs:21`）——**口播原文是模型看着画面编的**。
- **同一件事，它是拆解，我们是编造**。这条同时被另外两家印证：即梦有原生有声视频与音频参考；RunningHub 有「H3 锁音对嘴」把口播做成成品 [B]。

**判断**：这是「复刻」这块招牌上最贵的一条，也是我最建议先修的。补的动作：抽音轨 → ASR 出原文 → BGM 识别/推荐 → 分镜表加字段（运镜/景别/时长/人声/音乐节奏）。

### 0.3 我们没有「组织」这个实体，Agent 的产物也不和人的产物在同一张画布上

- **RunningHub 已有完整一套** [A]：团队账户 = 团队钱包 + 成员席位 + 成员额度 + 邀请链接 + **加入需管理员审批** + 任务/账单/LLM 日志**按成员留痕**；个人资源不随加入团队迁移。
- **LibTV 把 Agent 当第一等用户** [A/B]：一级导航有 `LibTV Agent BETA`，官方开源仓 `libtv-labs/libtv-skills` 走 OpenAPI（`LIBTV_ACCESS_KEY`，建会话/发生成/轮询/批量下载），**Agent 生成的项目落地为人类同一张画布的同一个 projectId**。
- **我们**：有账号、归属校验、admin 控制台、房间智能体 + `vqc_` 令牌 + MCP 收件箱；**没有组织/席位/额度/审批**；房间智能体的产物留在房间里，**不进画布、不进作品**。

**判断**：这是架构级差距，但它也刚好是「把能力卖出去」的前置条件——没有组织与额度的概念，团队客户没法采购。补的动作：数据模型加 org/team + 归属校验（注意既有要求：下载/成片接口必须按 cookie 或服务端签名判归属，不属于请求者 403）；再让房间里的产物能落到同一 projectId。

| 逐镜出图带不带商品 | — | 默认**不带商品参考图**（缺口审计），复刻出来的图往往不是这个商品 |
| 我们的差异（别丢） | 竞品的「同款」是**内容级复用**（即梦写进用户协议 9.6），不是参数级模板 | 我们有参数化模板 + `adapted-from` 来源足迹 + 未占用来源，这是更工程化的一套 |

## 4. 模板与社区

- **模板交易与分成**：RunningHub 有工作流市场 + AI 应用市场 + `creator-reward`/`my-income`（分成比例未核实）；LiblibAI 社区有收益榜 [A/B]。**我们模板库只做复用，没有交易、没有分成**。
- **社区曝光与赛事**：即梦「未来影像计划」、2026 创作者成长计划（参与得积分、优质短片最高 28888 积分、爆款 2000 元现金、优异者开星图白名单接商单）[B]；LibTV 有创作者挑战赛与百万奖金 [B]。**我们只有作品墙**，没有曝光位与激励。
- **发布审核**：即梦发布内容进社区要过《社区自律公约》分级审核；LibTV 发布后审核通过才曝光 [A/B]。**我们分享链接永久有效且无口令**（缺口审计第 4 条）——**先收紧分享，再谈社区**。
- **「同款」的授权口径**：即梦把「他人可对你发布的内容做同款、当参考图、再生成」写进用户协议 [A]。我们要做同款，得先把内容级授权的写法定下来。

## 6. 商业化与合规

- **支付闭环**：竞品都能下单买会员/积分；我们充值通道关着，且 `auto` 会白送到账。**先关 auto，再谈支付**。
- **失败退款写成对外承诺**：RunningHub 与即梦的失败退款规则**都查不到**（未核实），而我们已实现「先扣后调、失败全额退回、留 error 消息」。**这是我们能当卖点写出来的地方**。
- **备案与标识**：即梦公示 5 个模型备案 + 算法备案编号，协议 4.2 写 AI 标识条款；接入方还要自己再做安全评估与备案 [A]。我们明确未办，只有生成后 AI 标识。**对 B 端交付是硬门槛**。
- **上传口合规拦截**：LibTV 自动拦截含写实真人脸的素材（图与视频都不行）[B]；即梦限制真人脸参考、给三条替代（本账号近 30 天产出 / 官方虚拟人像 / 已授权素材）[A]。**我们只有生成后的标识，上传口没有拦截**。
- **自助注册**：竞品手机号即可注册；我们 `VQ_REGISTRATION=0`，邀请码或管理员开号，手机号只能登录不能注册/找回（缺口审计第 3 条）。

## 7. 平台化的其他差距

- **移动端 App**：Picset 已上架 App Store（跳帧工场（杭州）科技有限公司）[B]；我们只有 Web。
- **国际化**：Picset 站点声明 13 个 hreflang、界面 11 种语言，主攻跨境出海 [A/B]；我们以中文为主。
- **水印策略**：竞品默认带品牌水印、会员去水印（即梦协议 9.8 还禁止去掉品牌标识）；我们界面水印已删、输出也不烧——**等于少一个卖点，但也没有合规把柄**，维持现状即可。

## 8. 我们更强的地方（追赶时别丢）

1. **「复刻 → 评审 → 交付 → 回执 → 版本对比」是真闭环**：zip + sha256 + 回执打开次数 + 项目版本 diff，四家竞品都没有同等交付物。
2. **视觉评审是真能力**：service / local-model 双 provider + 像素锚点 + 评审队列；竞品只有「发布审核」这种二元门。
3. **失败退款 + 断点续跑**已实现；竞品这块反而查不到规则。
4. **聊天室里能接用户自己的 codex / Claude**（连接器 + `vqc_` 令牌）；竞品的 Agent 是平台自营、不可替换。
5. **爆款检索（红狐）+ 来源足迹 + 未占用来源**；LibTV 的「全网爆款」是自家作品精选，不是可检索的爆款库。
6. **单位经济学有模型**（成本→加价→积分一条公式可改）；竞品是黑箱点数。
7. **无限画布不自己造**：用票据 + 排队位把外部 Source-Available 画布接进来，省了半年（代价：能力与失败审计不到）。

## 9. 建议的讨论顺序（我的排序）

1. **先修「复刻是假的」**（0.2）：抽音轨 + ASR + BGM + 分镜表字段。理由：这是主线招牌，也是广告里最容易被戳穿的一句；改动集中在 `frames.mjs` / `vision.mjs` / 模板字段，代价可控。
2. **再堵钱的口子**（0.1）：关掉 `auto`、内测直充只给管理员，对外价目表成型。理由：注册一开放就漏水，五分钟能加一道门。
3. **然后才谈「组织 + Agent 化成商品」**（0.3、第 5 节）：团队席位与额度、房间产物进画布、对外 API key。理由：它是架构级动作，也是 B 端采购的前置，但要等前面两条站住。
4. **生成层硬缺按买单的人挑**：电商客户 → 数字人/对口型 + 商品参考图 + 电商规格层；短剧/自媒体客户 → 时长与分辨率、音频、剪辑工程包。**不建议平铺全补**（我们只有两三个视频型号，先补「能卖出去的那两个」）。

## 未核实 / 抓不到的（如实列出，不猜）

- **搜索端点已经欠费**：调研中途 `web_search` 返回 **HTTP 402 Insufficient Balance**，之后无法再检索；pixai.art 因此未核实。
- LibTV：会员档位明细、失败退款规则、API 计费、是否官方 MCP、导出剪映。
- RunningHub：创作者分成比例与结算、失败退款规则、发票与第三方费用细则。
- 即梦：应用内「积分/条」换算、失败/审核失败是否退积分、「视频 3.0」这个模型名、参数化模板库、剪映工程包导出。
- Picset：档位名称与计费单位（/pricing 是 SPA 空壳）、是否有 API/MCP；**且它已改名 Picell AI（picell.ai），picsetai.com 正在退役，后续跟踪对象要换。**
- PixArt：用户说的「PixArt」经核实是**开源论文模型 PixArt-α/δ**（arXiv 2310.00426 / 2401.05252），不是产品平台；机构归属、许可证、商用条款未核实。
