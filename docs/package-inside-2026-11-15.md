# 包里那份：不用解压，点开就能看（v0.9.129，2026-11-15）

## 问题

封存包做出来之后，作品页只告诉你「包里 10 个文件、243 KB」——那份清单是**封存时记下来的一行行名字**，不是包本身。想确认「当初交给甲方的现场页到底长什么样」「第五张帧图是不是打错了」「两版对照页有没有塞进去」，只有一条路：先下载 243 KB 的 zip，再解压，再从一堆同名文件里认出哪一个。半年后回看一条交付，最麻烦的恰好是这一步。

另一件事：档案里记的清单和包里真有的条目，从来没有当面对过。清单可能被升级前的旧记录漏掉，包也可能被人换过一整份——v0.9.128 的整包哈希能发现「不是当初那一份」，却发现不了「这一份里的目录跟档案记得不一样」。

## 做法

- **读包本身**：新增 `server/zip-read.mjs`，解析 ZIP 的中央目录（EOCD → 中央目录 → 每条的本地头），拿到条目名、字节数、CRC32、压缩方式与偏移；只认 store（0）与 deflate（8），别的、ZIP64、被截断的一律回 null，不猜一份清单。
- **只读目录路由**：`GET /api/projects/:id/delivery-packages/:pid/content`。读盘上那份封存包，列出条目（名字 / 字节数 / 类别），并把**档案记的清单**与**包里真有的条目**对一遍，差在哪就说哪（老包没记清单就不比较，不把整包说成「多出来的」）。
- **按条目取一条**：`GET .../content/<条目名>`。名字只认目录里真有的那一条（带 `..`、空段、超长一律不认），解开后**先验 CRC32 再发**：对不上回 409 并写清「包在这一块坏了」，不把坏字节当内容展示。
- **界面**：「清单」改成从盘上那份读出来的目录，一条一条都能点：文字进 `<pre>`、图片进 `<img>`、HTML 页面进沙箱 `<iframe>`（`allow-same-origin`，没有 `allow-scripts`），页面里还有「原样打开」在新标签里按原样看。
- **退回也要说清**：盘上那份没了 / 包被截断时，目录读不出来就如实写，然后把档案里记的清单摆出来，标明「点不开预览，下载下来看」——不拿今天的样子补一份。
- **不改边界**：只读，不缓存、不解压到磁盘、不写任何文件；封存包仍只认登录态，没有公开地址。

## 踩坑

1. **验收跑的是构建产物**：改完 `sandbox` 属性不重新 `npm run build`，E2E 里 `iframe.contentDocument` 永远是 null（沙箱不给同源），会被误判成「页面没渲染」。顺序必须是：改源码 → 构建 → 再跑浏览器。
2. **`sandbox=""` 下 CSP 的 `'self'` 匹配不上任何地址**：不透明源让现场页里的相对帧图全被 `img-src 'self'` 拦掉。改成 `sandbox="allow-same-origin"`（没有 `allow-scripts`，脚本仍跑不起来）后图都出来，CSP 也照旧挡住内联脚本。
3. **JSX 的 `{/* */}` 不能写在 `? ( … )` 的表达式位置**：只能放在 JSX 子节点里，写进表达式位会报 `')' expected`；注释要写成 `//` 放在括号里。
4. **前端异常上报会把故意弄坏的图记一条**：`POST /api/client-errors`（kind=resource）。断言写请求时要按这个路径排除，否则「0 写请求」永远不成立。
5. **PowerShell 双引号里的 `$f` / `$p` 会在本地就展开**：远程 for 循环拿到空串（`sha256sum /opt/visionqa/` → Is a directory）。查生产的循环一律写成脚本文件 scp 过去跑。
6. **公网域名是 `visionqa.wavisionai.cn`**，不是 `visionqa.wavision.com`；写错时先怀疑域名（server_name 里根本没有那个名字），别先怀疑部署。
7. **每条预览都会把整份包读进内存一次**：248 KB 的夹具无所谓，60 MB 的包连点五张图就是五次整份读。现在有 64 MB 上限（超了 413），按范围读留给后面。

## 发现但没做

- 预览图片要整份读包（可以改成按条目偏移做范围读取）；条目也有 32 MB 的单条上限。
- 没有逐条 CRC 的批量自检（只在你点开某一条时验那一条）；没有把 CRC32 结果写回档案。
- HTML 预览是沙箱里的原样页面，窄屏上要横向滚动（页面本身是 A4 宽）；没有做缩放预览。
- 没有下载次数 / 保留期 / 异地备份 / 定期巡检告警（缺告警 webhook）。
- 手机上只有点选，没有拖放；生产 0 条交付，真包只有本地的。
